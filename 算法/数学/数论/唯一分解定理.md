算术基本定理（唯一分解定理）是数论的基石。在算法竞赛中，它指出：任何一个大于 1 的正整数 $N$，都可以唯一地分解为有限个质数的乘积。

用数学公式表达为：
$$N = p_1^{c_1} \cdot p_2^{c_2} \cdot \dots \cdot p_k^{c_k}$$

其中，$p_i$ 为互不相同的质数（通常规定 $p_1 < p_2 < \dots < p_k$），且 $c_i$ 为正整数（代表该质因数的指数或个数）。

在算法竞赛（如 Codeforces 等平台）中，质因数分解主要分为以下三种场景及对应的算法：

## 1. 单个数的质因数分解：试除法 (Trial Division)

**适用场景：** 对单个数 $N$ 进行分解，且 $N \le 10^{12}$。

**核心思想：**

一个合数 $N$ 最多只有一个大于 $\sqrt{N}$ 的质因子。因此，我们只需要从小到大枚举 $2$ 到 $\sqrt{N}$ 之间的所有数 $i$：

- 如果 $i$ 能整除 $N$，说明 $i$ 是 $N$ 的一个质因子。  
    
- 不断将 $N$ 除以 $i$，直到不能整除为止，同时记录除的次数（即指数 $c_i$）。
    
- 循环结束后，如果 $N > 1$，说明剩下的 $N$ 就是那个唯一大于 $\sqrt{N}$ 的质因子。  

**C++ 实现：**

C++

```C++
#include <iostream>
#include <vector>

using namespace std;

// 返回值：每对 pair 表示 {质因子 p_i, 指数 c_i}
vector<pair<long long, int>> primeFactorize(long long n) {
    vector<pair<long long, int>> factors;
    for (long long i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            int count = 0;
            while (n % i == 0) {
                count++;
                n /= i;
            }
            factors.push_back({i, count});
        }
    }
    // 处理可能存在的大于 sqrt(n) 的质因子
    if (n > 1) {
        factors.push_back({n, 1});
    }
    return factors;
}
```

**复杂度：** 时间复杂度为 $O(\sqrt{N})$，空间复杂度为 $O(\log N)$。

## 2. 大批量数的质因数分解：最小质因子筛 (SPF)

**适用场景：** 需要对 $10^5$ 到 $10^6$ 次查询进行分解，且数字范围 $N \le 10^7$。

**核心思想：**

如果对每次查询都使用 $O(\sqrt{N})$ 的试除法，大量查询会导致超时（TLE）。可以借助**欧拉筛（线性筛）** 在 $O(M)$ 的时间预处理出 $1$ 到 $M$ 内每个数的**最小质因子 (Smallest Prime Factor, SPF)**。

查询数字 $N$ 时，每次让 $N$ 除以它的最小质因子 `spf[N]`，可以像查字典一样在 $O(\log N)$ 时间内完成分解。

**C++ 实现：**
C++

```C++
const int MAXN = 10000005;
int spf[MAXN]; // 记录每个数的最小质因子
vector<int> primes;

// 1. 预处理：O(N) 线性筛
void eulerSieve(int n) {
    for (int i = 2; i <= n; i++) {
        if (spf[i] == 0) { // i 是质数
            spf[i] = i;
            primes.push_back(i);
        }
        for (int p : primes) {
            if (p * i > n) break;
            spf[p * i] = p; // 核心：记录最小质因子
            if (i % p == 0) break; // 保证每个数只被其最小质因子筛掉
        }
    }
}

// 2. O(log N) 极速查询
vector<pair<int, int>> fastFactorize(int n) {
    vector<pair<int, int>> factors;
    while (n > 1) {
        int p = spf[n];
        int count = 0;
        while (n % p == 0) {
            count++;
            n /= p;
        }
        factors.push_back({p, count});
    }
    return factors;
}
```

## 3. 超大数的质因数分解：Pollard's Rho 算法

**适用场景：** 对单个数 $N$ 进行分解，且 $N \le 10^{18}$（例如 Codeforces 上的高难度数论题）。

如果 $N = 10^{18}$，试除法需要 $10^9$ 次运算，必然超时。

**核心思想：** Pollard's Rho 是一种基于随机游走和生日悖论的概率启发式算法。它通过生成一个伪随机序列，利用 $O(N^{1/4})$ 的期望时间复杂度找到 $N$ 的一个非平凡因子，再配合 Miller-Rabin 素性测试递归分解。竞赛中通常作为模板直接套用。

此模板使用了 `__int128_t` 来避免 1018×1018 时的溢出问题，极大简化了代码（无需手写 `O(1)` 快速乘）。

C++

```C++
#include <iostream>
#include <vector>
#include <numeric>
#include <algorithm>
#include <map>

using namespace std;

typedef long long ll;

// 快速幂 a^b % mod
ll power(ll a, ll b, ll mod) {
    ll res = 1;
    a %= mod;
    while (b > 0) {
        if (b & 1) res = (ll)((__int128_t)res * a % mod);
        a = (ll)((__int128_t)a * a % mod);
        b >>= 1;
    }
    return res;
}

// Miller-Rabin 素性测试
bool Miller_Rabin(ll n) {
    if (n < 2) return false;
    if (n == 2 || n == 3) return true;
    if (n % 2 == 0) return false;

    ll d = n - 1;
    int s = 0;
    while (d % 2 == 0) {
        d /= 2;
        s++;
    }

    // 对于 10^18 以内的数，测试这 9 个基底是确定的
    int bases[] = {2, 3, 5, 7, 11, 13, 17, 19, 23};
    for (int a : bases) {
        if (n <= a) break;
        ll x = power(a, d, n);
        if (x == 1 || x == n - 1) continue;

        bool composite = true;
        for (int i = 0; i < s - 1; i++) {
            x = (ll)((__int128_t)x * x % n);
            if (x == n - 1) {
                composite = false;
                break;
            }
        }
        if (composite) return false;
    }
    return true;
}

// 寻找绝对值
ll abs_val(ll x) { return x < 0 ? -x : x; }

// 求最大公约数
ll gcd(ll a, ll b) {
    return b == 0 ? a : gcd(b, a % b);
}

// Pollard's Rho 找一个非平凡因子
ll Pollard_Rho(ll n) {
    if (n % 2 == 0) return 2;
    ll x = 0, y = 0, c = rand() % (n - 1) + 1;
    ll d = 1;
    // f(x) = (x^2 + c) % n
    auto f = [&](ll val) { return (ll)(((__int128_t)val * val + c) % n); };

    // 龟兔赛跑找环
    for (int step = 1, goal = 1; ; step++) {
        x = f(x);
        d = gcd(abs_val(x - y), n);
        if (d > 1 && d < n) return d;
        if (x == y) return n; // 陷入死循环，未找到因子（返回 n 并在主函数重试）
        
        // 倍增步长优化判环
        if (step == goal) {
            y = x;
            goal *= 2;
        }
    }
}

// 递归分解
void factorize(ll n, map<ll, int>& factors) {
    if (n < 2) return;
    if (Miller_Rabin(n)) {
        factors[n]++;
        return;
    }
    ll p = n;
    while (p >= n) {
        p = Pollard_Rho(n); // 如果找因子失败(返回了n)，换随机数重新找
    }
    factorize(p, factors);
    factorize(n / p, factors);
}

// --- 使用示例 ---
int main() {
    // 提速
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int t; 
    if (cin >> t) {
        while (t--) {
            ll n;
            cin >> n;
            map<ll, int> factors;
            factorize(n, factors);

            cout << n << " = ";
            bool first = true;
            for (auto const& [prime, count] : factors) {
                if (!first) cout << " * ";
                cout << prime << "^" << count;
                first = false;
            }
            cout << "\n";
        }
    }
    return 0;
}
```

> **模板细节注意：** 当 `Pollard_Rho` 函数返回 N 时，说明本次随机常数 c 运气不佳，陷入了平凡环。代码中的 `while (p >= n)` 会自动重新生成新的 c 继续尝试，直到成功找到真因子为止。
## 唯一分解定理在竞赛中的三大核心推论

利用唯一分解定理 $N = p_1^{c_1} p_2^{c_2} \dots p_k^{c_k}$，可以直接秒杀以下常见问题：

  

### 1. 求正约数个数 $d(N)$

根据乘法原理，每个质因子 $p_i$ 可以被选取 $0, 1, 2, \dots, c_i$ 次，共 $(c_i + 1)$ 种选法。

  

$$d(N) = (c_1 + 1) \times (c_2 + 1) \times \dots \times (c_k + 1)$$

### 2. 求正约数之和 $\sigma(N)$

将所有约数组合展开，刚好等价于多个等比数列求和的乘积：

  

$$\sigma(N) = (1 + p_1 + p_1^2 + \dots + p_1^{c_1}) \dots (1 + p_k + p_k^2 + \dots + p_k^{c_k})$$

### 3. 求欧拉函数 $\phi(N)$ （小于等于 $N$ 且与 $N$ 互质的数的个数）

基于容斥原理，可以从唯一分解定理直接推导出计算公式：

  

$$\phi(N) = N \times \left(1 - \frac{1}{p_1}\right) \times \left(1 - \frac{1}{p_2}\right) \times \dots \times \left(1 - \frac{1}{p_k}\right)$$

在写代码时，为避免浮点数误差，通常写作 `ans = ans / p * (p - 1)`。
