在算法竞赛中，**欧拉函数（Euler's Totient Function）**，通常记作 $\varphi(n)$，是数论板块中最核心的概念之一。它表示在从 $1$ 到 $n$ 的正整数中，与 $n$ 互质的数的个数。

## 核心计算公式

根据算术基本定理，如果将 $n$ 分解为质因数的乘积 $n = p_1^{k_1} p_2^{k_2} \dots p_m^{k_m}$，那么欧拉函数的通项公式为：
$$\varphi(n) = n \times \left(1 - \frac{1}{p_1}\right) \times \left(1 - \frac{1}{p_2}\right) \times \dots \times \left(1 - \frac{1}{p_m}\right)$$
## 竞赛中必须熟记的性质

1. **积性函数**：如果 $\gcd(a, b) = 1$，那么 $\varphi(a \times b) = \varphi(a) \times \varphi(b)$。
    
2. **质数性质**：若 $p$ 为质数，则 $\varphi(p) = p - 1$。
      
3. **质数次幂**：若 $p$ 为质数，则 $\varphi(p^k) = p^k - p^{k-1}$。
    
4. **约数和性质**：$n$ 的所有正约数的欧拉函数之和等于 $n$，即 $\sum_{d\vert{}n} \varphi(d) = n$。
    
5. **欧拉定理**：若 $\gcd(a, m) = 1$，则 $a^{\varphi(m)} \equiv 1 \pmod m$。  

## 核心算法实现模板（C++）

### 1. 求单个数的欧拉函数 $O(\sqrt{n})$

利用试除法分解质因数，同时根据公式计算 $\varphi(n)$。这种方法适用于只需要求少数几个极大数字的欧拉函数。

C++

```C++
long long euler_phi(long long n) {
    long long ans = n;
    for (long long i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            ans = ans / i * (i - 1); // 等价于 ans = ans * (1 - 1/i)
            while (n % i == 0) {
                n /= i; // 把当前质因子除干净
            }
        }
    }
    // 如果最后 n > 1，说明存在一个大于 sqrt(原n) 的质因子
    if (n > 1) {
        ans = ans / n * (n - 1);
    }
    return ans;
}
```

### 2. 线性筛（欧拉筛）求 $1 \sim n$ 的欧拉函数 $O(n)$

在竞赛中，更常见的情况是需要预处理出 $1$ 到 $n$ 所有数的欧拉函数。我们可以结合线性筛素数的算法，在 $O(n)$ 时间内完成。

**核心递推逻辑：**

- 若 $i$ 是质数，$\varphi(i) = i - 1$。
    
- 若 $i \bmod p = 0$（$p$ 是 $i$ 的最小质因子），则 $i \times p$ 的质因子种类和 $i$ 相同。根据公式，$\varphi(i \times p) = \varphi(i) \times p$。  
    
- 若 $i \bmod p \neq 0$（$p$ 和 $i$ 互质），利用积性函数性质，$\varphi(i \times p) = \varphi(i) \times \varphi(p) = \varphi(i) \times (p - 1)$。  

C++

```C++
#include <vector>

using namespace std;

const int MAXN = 1e6 + 5;
int phi[MAXN];
int primes[MAXN], cnt;
bool is_prime[MAXN];

void sieve_phi(int n) {
    for (int i = 0; i <= n; i++) is_prime[i] = true;
    is_prime[0] = is_prime[1] = false;
    phi[1] = 1;
    cnt = 0;

    for (int i = 2; i <= n; i++) {
        if (is_prime[i]) {
            primes[cnt++] = i;
            phi[i] = i - 1; // 质数的欧拉函数
        }
        for (int j = 0; j < cnt && i * primes[j] <= n; j++) {
            is_prime[i * primes[j]] = false;
            if (i % primes[j] == 0) {
                // i 包含了 primes[j] 这个质因子
                phi[i * primes[j]] = phi[i] * primes[j];
                break; 
            } else {
                // i 和 primes[j] 互质
                phi[i * primes[j]] = phi[i] * (primes[j] - 1);
            }
        }
    }
}
```

## 典型竞赛应用场景

1. **处理超大指数的快速幂（扩展欧拉定理）**
    
    当遇到 $a^b \pmod m$ 且 $b$ 非常大（甚至是以字符串形式给出，或者 $b$ 也是一个指数塔）时，可以用扩展欧拉定理降幂：
    $$a^b \equiv \begin{cases} a^b, & b < \varphi(m) \\ a^{(b \bmod \varphi(m)) + \varphi(m)}, & b \ge \varphi(m) \end{cases} \pmod m$$
    
    注意，这个公式**不需要** $\gcd(a, m) = 1$ 这个前置条件。
    
2. **化简含有 $\gcd$ 的求和式**
    
    利用性质 $\sum_{d\vert{}n} \varphi(d) = n$，可以把原式中的 $n$ 替换为欧拉函数的求和，随后改变求和顺序（类似于莫比乌斯反演），大幅降低时间复杂度。比如求 $\sum_{i=1}^n \sum_{j=1}^n \gcd(i, j)$ 时，欧拉函数是标准的优化工具。
