前置知识：[[乘法快速幂]]  [[乘法逆元]]

根据费马小定理，当 **p 为质数**且 **a 不能被 p 整除**时，满足以下同余关系：

$$a^{p-1} \equiv 1 \pmod p$$

将等式左边提取一个 $a$ 出来，可以转换为：

$$a \cdot a^{p-2} \equiv 1 \pmod p$$

在模 $p$ 运算中，如果存在一个数 $x$ 使得 $a \cdot x \equiv 1 \pmod p$，那么 $x$ 就是 $a$ 的乘法逆元。通过上面的推导可以清晰地看出，**$a$ 模 $p$ 的乘法逆元就是 $a^{p-2} \pmod p$**。

结合你提供的快速幂函数 `power(ll a, ll b, ll p)`，求逆元的过程实际上就是计算 $a$ 的 $p-2$ 次方对 $p$ 取模的结果。我们只需要直接调用这个函数，将指数 `b` 传入为 `p - 2` 即可。

**基于你的模板封装求逆元的代码：**

C++

```C++
typedef long long ll;
ll power(ll a, ll b, ll p) {
    ll res = 1; 
    while(b > 0) {
        if(b % 2 == 1) {
            res = (res * a) % p;
        }
        a = (a * a) % p;
        b >>= 1;
    }
    return res;
}
// 使用费马小定理求逆元
ll get_inverse(ll a, ll p) {
    // 逆元即为 a^(p-2) mod p
    return power(a, p - 2, p);
}
```

**应用限制与细节：**

- **模数限制**：`p` 必须是质数（如算法竞赛中常见的 $10^9+7$ 或 $998244353$）。如果 `p` 不是质数，费马小定理不成立，此时需要改用扩展欧几里得算法（exGCD）求逆元。
    
- **边界条件**：如果 $a$ 是 $p$ 的倍数（即 $a \equiv 0 \pmod p$），则 $a$ 不存在模 $p$ 的逆元。
    
- **复杂度**：快速幂算法会将指数 $p-2$ 进行二进制拆分，循环次数为 $\log_2(p-2)$，因此求一次逆元的时间复杂度为 $O(\log p)$，在极短时间内即可完成运算。
