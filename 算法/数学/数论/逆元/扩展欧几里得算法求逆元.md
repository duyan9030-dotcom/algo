在算法竞赛中，求模乘法逆元是一个非常基础且高频的考点。拓展欧几里得算法（Extended Euclidean Algorithm，简称 Exgcd）是求逆元最通用、最核心的方法之一。
### 一、 什么是乘法逆元？

在模算术中，除以一个数等于乘以这个数的**逆元**。

如果存在一个整数 $x$，使得 $a$ 乘以 $x$ 后，对 $m$ 取模的结果为 $1$，即：

$$a \cdot x \equiv 1 \pmod m$$

那么我们就称 $x$ 为 $a$ 在模 $m$ 意义下的**乘法逆元**（常记为 $a^{-1}$）。

**存在前提**：

$a$ 在模 $m$ 下存在逆元的**充要条件**是 $a$ 与 $m$ 互质，即 $\gcd(a, m) = 1$。如果它们不互质，逆元不存在。
### 二、 为什么可以用 Exgcd 求逆元？

我们将同余方程 $a \cdot x \equiv 1 \pmod m$ 转换成等式。

如果 $a \cdot x$ 除以 $m$ 的余数是 $1$，意味着 $a \cdot x$ 是 $m$ 的某个倍数再加上 $1$。即存在某个整数 $y$，使得：
$$a \cdot x = -m \cdot y + 1$$

移项后可以得到一个二元一次方程：
$$a \cdot x + m \cdot y = 1$$

根据**裴蜀定理（Bézout's identity）**，对于任意整数 $a$ 和 $b$，方程 $a \cdot x + b \cdot y = \gcd(a, b)$ 一定存在整数解。

因为逆元存在的前提是 $\gcd(a, m) = 1$，所以方程恰好变成：
$$a \cdot x + m \cdot y = \gcd(a, m) = 1$$

这正是**拓展欧几里得算法**用来求解的标准方程！我们只需要用 Exgcd 解出 $a \cdot x + m \cdot y = 1$ 中的 $x$，这个 $x$ 就是我们要找的逆元。

### 三、 Exgcd 的算法推导

普通的欧几里得算法（辗转相除法）基于这样一个性质：
$$\gcd(a, b) = \gcd(b, a \bmod b)$$

Exgcd 在辗转相除的同时，维护 $x$ 和 $y$ 的值。

假设在我们递归求解 $\gcd(a, b)$ 的下一层，已经求出了 $b$ 和 $a \bmod b$ 对应的系数 $x_1$ 和 $y_1$，使得：
$$b \cdot x_1 + (a \bmod b) \cdot y_1 = \gcd(a, b)$$

我们知道取模运算可以写成：$a \bmod b = a - \lfloor \frac{a}{b} \rfloor \cdot b$。将其代入上式：
$$b \cdot x_1 + \left(a - \lfloor \frac{a}{b} \rfloor \cdot b\right) \cdot y_1 = \gcd(a, b)$$

展开并重新合并同类项，把 $a$ 和 $b$ 提出来：
$$a \cdot y_1 + b \cdot \left(x_1 - \lfloor \frac{a}{b} \rfloor \cdot y_1\right) = \gcd(a, b)$$

对比原方程 $a \cdot x + b \cdot y = \gcd(a, b)$，我们得到了递推关系：
- $x = y_1$ 
    
- $y = x_1 - \lfloor \frac{a}{b} \rfloor \cdot y_1$

**递归的边界**：

当 $b = 0$ 时，$\gcd(a, 0) = a$。此时方程变为 $a \cdot x + 0 \cdot y = a$，显然可以取 $x = 1, y = 0$。
### 四、 C++ 代码模板

在算法竞赛中，为了防止中间计算溢出，通常使用 `long long`。
C++

```C++
#include <iostream>
using namespace std;

typedef long long ll;

// 拓展欧几里得算法求 ax + by = gcd(a, b) 的一组解 (x, y)
// 函数返回值为 gcd(a, b)
ll exgcd(ll a, ll b, ll &x, ll &y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }
    ll x1, y1;
    ll d = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return d;
}

// 封装求逆元的函数
// 求 a 在模 m 下的逆元，如果不存在返回 -1
ll get_inverse(ll a, ll m) {
    ll x, y;
    ll d = exgcd(a, m, x, y);
    if (d != 1) {
        return -1; // 此时 gcd(a, m) != 1，逆元不存在
    } else {
        // Exgcd 求出的 x 可能是负数，需要将其转化为 [0, m-1] 内的正整数
        return (x % m + m) % m;
    }
}

int main() {
    ll a = 3, m = 11;
    ll inv = get_inverse(a, m);
    if (inv != -1) cout << a << " modulo " << m << " inverse is: " << inv << endl;
    else cout << "Inverse does not exist." << endl;
    return 0;
}
```

### 五、 竞赛中的核心注意点

1. **负数处理（极其重要）**：
    
    Exgcd 算出来的解 $(x, y)$ 只是无穷多组解中的一组。求出的 $x$ 极有可能是负数。
    
    对于模 $m$ 意义下的逆元，我们通常需要的是最小非负整数。
    
    所以在拿到 $x$ 后，**必须执行** `(x % m + m) % m` 进行正数化处理。
    
2. **Exgcd 与 费马小定理 的对比选择**：
    
    - **费马小定理**：$a^{m-2} \equiv a^{-1} \pmod m$。代码用快速幂即可实现。但它有一个**致命限制**：$m$ 必须是质数！  
        
    - **Exgcd**：没有要求 $m$ 必须是质数，**只要求 $\gcd(a, m) = 1$ 即可**。当你在题目中遇到模数不保证为质数（比如 RSA 算法相关的题目，或者特殊的合数模数）时，必须使用 Exgcd 求逆元。  
    
3. **时间复杂度**：
    
    Exgcd 求单次逆元的时间复杂度和欧几里得算法一致，为 $O(\log(\min(a, m)))$，非常快。
    
    _(注：如果题目要求求 $1 \sim n$ 的所有数的逆元，单次 $O(\log N)$ 会超时，应该使用 $O(N)$ 的线性求逆元算法。)_
