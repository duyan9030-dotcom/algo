在算法竞赛或组合数学问题中，我们经常需要频繁计算组合数 $C(n, m) = \frac{n!}{m!(n-m)!} \pmod p$。如果每次都用快速幂去求 $m!$ 和 $(n-m)!$ 的逆元，时间复杂度会达到 $O(n \log p)$，在频繁查询时会超时。

为了实现 $O(1)$ 查询，我们可以利用**阶乘逆元的递推公式**，在 $O(n)$ 的线性时间内预处理出所有阶乘的逆元。这个方法巧妙地结合了上文提到的**费马小定理**。

### 阶乘逆元的递推公式推导

我们设 $fac[i]$ 表示 $i! \pmod p$，设 $invFac[i]$ 表示 $(i!)^{-1} \pmod p$（即 $i$ 阶乘的乘法逆元）。

已知阶乘的递推关系：

$$i! = (i-1)! \cdot i$$

将等式两边同时取模 $p$ 意义下的乘法逆元：

$$(i!)^{-1} \equiv ((i-1)! \cdot i)^{-1} \pmod p$$

$$(i!)^{-1} \equiv ((i-1)!)^{-1} \cdot i^{-1} \pmod p$$

将等式两边同时乘以 $i$：

$$(i!)^{-1} \cdot i \equiv ((i-1)!)^{-1} \pmod p$$

替换成我们设定的数组表示，就得到了**阶乘逆元的逆向递推公式**：

$$invFac[i-1] \equiv invFac[i] \cdot i \pmod p$$

### 核心计算步骤

基于上述公式，预处理的思路是“**正向求阶乘，单次求逆元，逆向推逆元**”：

1. **正向计算阶乘**：从 $1$ 到 $n$，递推求出所有的 $fac[i]$。
    
2. **费马小定理求边界**：对最大的阶乘 $fac[n]$，利用**快速幂和费马小定理**，求出它的逆元 $invFac[n]$。（这是整个过程中唯一一次使用快速幂，耗时 $O(\log p)$）。
    
3. **逆向递推**：从 $n$ 往下递推到 $1$，利用公式 `invFac[i-1] = (invFac[i] * i) % p`，算出所有阶乘的逆元。
    

### 完整代码模板（包含组合数计算应用）

结合之前的快速幂，下面是求解阶乘逆元并计算组合数 $C(n, m)$ 的标准模板：

C++

```C++
typedef long long ll;
const int MAXN = 200005; // 根据题目需求设置最大范围
ll fac[MAXN];            // 存储阶乘
ll invFac[MAXN];         // 存储阶乘的逆元
ll p;                    // 模数，必须是质数

// 快速幂模板
ll power(ll a, ll b, ll p) {
    ll res = 1;
    while(b > 0) {
        if(b % 2 == 1) res = (res * a) % p;
        a = (a * a) % p;
        b >>= 1;
    }
    return res;
}

// 预处理阶乘及其逆元
void init(int n, ll p) {
    // 1. 正向递推阶乘
    fac[0] = 1;
    for(int i = 1; i <= n; i++) {
        fac[i] = (fac[i - 1] * i) % p;
    }
    
    // 2. 用费马小定理求最大阶乘 n! 的逆元
    invFac[n] = power(fac[n], p - 2, p);
    
    // 3. 逆向递推求其余阶乘的逆元
    for(int i = n; i >= 1; i--) {
        invFac[i - 1] = (invFac[i] * i) % p;
    }
}

// O(1) 查询组合数 C(n, m) = n! / (m! * (n-m)!) mod p
ll C(int n, int m, ll p) {
    if (m < 0 || m > n) return 0;
    // C(n, m) = fac[n] * invFac[m] * invFac[n-m] % p
    return fac[n] * invFac[m] % p * invFac[n - m] % p;
}
```

### 补充技巧：单个数的逆元也可以顺便求出

如果我们得到了阶乘数组 `fac[]` 和阶乘逆元数组 `invFac[]`，想要在 $O(1)$ 内求出任意单个数 $i$ 的逆元 $inv[i]$，也可以利用以下公式推导：

$$i^{-1} \equiv (i!)^{-1} \cdot (i-1)! \pmod p$$

写成代码即为：`inv[i] = (invFac[i] * fac[i-1]) % p`。这样整个单数逆元数组也能在预处理时 $O(1)$ 顺便推出来了。
