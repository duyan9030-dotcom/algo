在算法竞赛（ACM/ICPC, Codeforces, 蓝桥杯等）中，同余原理（Congruence）是数论板块最基础也是最重要的核心。很多组合数学、图论计数或动态规划的题目最终都会要求“将答案对 $10^9+7$ 或 $998244353$ 取模”，这就要求我们必须熟练掌握同余体系下的运算法则。

以下是算法竞赛中同余原理的详细讲解，由浅入深分为五个部分：
### 一、 基础同余性质与四则运算

**1. 定义：**

如果两个整数 $a$ 和 $b$ 满足 $(a - b)$ 能被 $m$ 整除，即 $m \mid (a-b)$，则称 $a$ 和 $b$ 对模 $m$ 同余，记作：
$$a \equiv b \pmod m$$

**2. 基础运算法则：**

在加、减、乘法中，同余式可以直接拆解（分配律）：

- **加法：** $(a + b) \bmod m = ((a \bmod m) + (b \bmod m)) \bmod m$
    
- **乘法：** $(a \times b) \bmod m = ((a \bmod m) \times (b \bmod m)) \bmod m$
    
- **减法（竞赛易错点）：**
    
    在 C++ 等语言中，负数取模的结果是负数（例如 `-5 % 3 = -2`），但在数学上我们需要正余数。因此减法取模的标准写法是：
    
    $(a - b) \bmod m = ((a \bmod m) - (b \bmod m) + m) \bmod m$

⚠️ **警告：除法不能直接取模！**

$(a / b) \bmod m \neq ((a \bmod m) / (b \bmod m)) \bmod m$

为了在同余体系下做除法，我们需要引入“乘法逆元”。

### 二、 核心基石：快速幂（Fast Exponentiation）

在处理 $a^b \bmod m$ 时，如果 $b$ 很大（如 $10^9$），直接乘会超时。快速幂基于二进制拆分的思想，能在 $O(\log b)$ 时间内完成计算，是同余运算最常用的底层工具。

C++

```C++
long long fast_pow(long long a, long long b, long long m) {
    long long res = 1;
    a %= m;
    while (b > 0) {
        if (b & 1) res = (res * a) % m; // 如果当前最低位为1，乘入结果
        a = (a * a) % m;               // a 平方
        b >>= 1;                       // 右移一位
    }
    return res;
}
```

### 三、 跨越除法障碍：乘法逆元（Modular Multiplicative Inverse）

**1. 什么是逆元？**

在模 $m$ 意义下，除以一个数 $b$ 等价于乘以 $b$ 的逆元。

如果 $b \times x \equiv 1 \pmod m$，则称 $x$ 为 $b$ 在模 $m$ 下的逆元，记作 $b^{-1}$。

此时：$(a / b) \bmod m = (a \times b^{-1}) \bmod m$。

**2. 逆元的求法（竞赛三大法）：**

- **方法A：费马小定理（最常用）**
    
    **条件：** $m$ 必须是质数（如 $10^9+7, 998244353$），且 $b$ 不被 $m$ 整除。
    
    **定理：** $b^{m-1} \equiv 1 \pmod m \implies b \times b^{m-2} \equiv 1 \pmod m$
    
    **结论：** $b$ 的逆元就是 $b^{m-2} \bmod m$。直接用上面的**快速幂**求解即可，$O(\log m)$。
    
- **方法B：扩展欧几里得算法（exgcd）**
    
    **条件：** $b$ 和 $m$ 互质（$\gcd(b, m) = 1$ 即可，$m$ 不必须是质数）。
    
    **原理：** 求解线性同余方程 $b \times x + m \times y = 1$。
    
    C++
    
    ```C++
    long long exgcd(long long a, long long b, long long &x, long long &y) {
        if (b == 0) { x = 1; y = 0; return a; }
        long long d = exgcd(b, a % b, y, x);
        y -= a / b * x;
        return d;
    }
    // 调用 exgcd(b, m, x, y)，(x % m + m) % m 就是逆元
    ```
    
- **方法C：线性求逆元（打表）**
    
    **条件：** $m$ 是质数，需要求 $1 \sim N$ 所有数的逆元，且 $N$ 很大（如 $10^7$）。
    
    **公式：** $inv[i] = (m - m/i) \times inv[m \bmod i] \bmod m$
    
    可以在 $O(N)$ 时间内预处理出所有逆元，常用于组合数 $\binom{n}{m}$ 的阶乘逆元预处理。

### 四、 竞赛高阶同余定理

当题目难度上升时，会用到以下经典定理与算法：

#### 1. 欧拉定理与欧拉降幂（处理超大指数）

**定理：** 若 $\gcd(a, m) = 1$，则 $a^{\varphi(m)} \equiv 1 \pmod m$（$\varphi(m)$ 是欧拉函数，表示 $1 \sim m$ 中与 $m$ 互质的数的个数）。

**应用（扩展欧拉定理/降幂公式）：**

当指数 $b$ 极大（甚至以字符串形式给出，或是一个极大的塔 $a^{b^c}$），我们可以对指数取模：

$a^b \equiv a^{b \bmod \varphi(m) + \varphi(m)} \pmod m \quad (\text{当 } b \ge \varphi(m) \text{ 且不要求互质时})$

#### 2. 中国剩余定理 (CRT & EXCRT)

**应用场景：** 求解一元线性同余方程组。例如“一个数除以 3 余 2，除以 5 余 3，除以 7 余 2，求这个数”。

  

$$\begin{cases} x \equiv a_1 \pmod{m_1} \\ x \equiv a_2 \pmod{m_2} \\ ... \end{cases}$$

- **经典 CRT：** 要求所有模数 $m_i$ **两两互质**。通过构造法求解。
      
- **扩展 CRT (EXCRT)：** 模数 **不互质**。核心思想是每次取出两个方程，用 `exgcd` 判断是否冲突，并合并成一个新的同余方程，最终化简为一个方程。（这是 Codeforces 中后期的常考点）。
#### 3. 卢卡斯定理 (Lucas Theorem)

**应用场景：** 求极大的组合数 $\binom{n}{m} \bmod p$，其中 $n, m$ 很大（如 $10^{18}$），但模数 $p$ 是一个**较小的质数**（如 $p \le 10^5$）。

**公式：**

$$\binom{n}{m} \equiv \binom{n/p}{m/p} \times \binom{n \bmod p}{m \bmod p} \pmod p$$

可以递归将其转化为较小的组合数求解。

  

#### 4. 大步小步算法 (Baby-Step Giant-Step, BSGS)

**应用场景：** 求解离散对数问题。即已知 $a, b, m$，求解最小的非负整数 $x$ 使得：

$$a^x \equiv b \pmod m$$

**思想：** 典型的“分块 / 空间换时间”。令 $x = i \times t - j$，其中 $t = \lceil\sqrt{m}\rceil$。将方程化为 $a^{i \times t} \equiv b \times a^j \pmod m$。将右边所有可能的值存入 Hash 表，再枚举左边去查表。复杂度 $O(\sqrt{m})$。

  

### 五、 算法竞赛实战避坑指南（Checklist）

1. **中间运算溢出 (`long long` 爆炸)：**
    
    计算 `(A * B) % m` 时，即使 A 和 B 都在 `long long` 范围内，`A * B` 也可能超过 `2^63-1` 导致溢出报错。
    
    _解决方案：_ 在 C++ 中，直接强制转换使用 `__int128`：
    
    `long long res = (long long)((__int128)A * B % m);`
    
2. **时刻提防负数取模：**
    
    特别是在维护树状数组/线段树做区间减法，或者多项式减法时，一定要写 `ans = (ans % M + M) % M`。
    
3. **检查模数是不是质数：**
    
    题目给的是 $998244353$（质数，随便用费马小定理逆元）还是 $998244352$（非质数，求逆元必须用 exgcd，或者可能根本不存在逆元需要特殊处理）？
    
4. **预处理阶乘逆元：**
    
    在求组合数 $\binom{n}{m} = \frac{n!}{m!(n-m)!} \bmod p$ 时，千万不要每次询问都去算逆元（复杂度 $O(Q \log p)$ 会 TLE）。正确的做法是：
    
    $O(N)$ 预处理出 $n! \bmod p$ 的数组 `fact[]`，然后求出 `fact[N]` 的逆元 `infact[N]`，再倒推预处理出所有阶乘的逆元：`infact[i-1] = infact[i] * i % p`。这样每次查询只需 $O(1)$。
