在算法竞赛（Competitive Programming）中，位运算因其执行速度极快且能优雅地解决特定类型的问题（如集合操作、状态压缩、博弈论等）而备受青睐。

### 一、经典基础技巧与性质

**1. 快速判断 2 的幂次**

- **公式**：`x > 0 && (x & (x - 1)) == 0`
    
- **原理**：$2$ 的幂次在二进制下只有最高位是 $1$，其余全为 $0$（如 $8$ 是 `1000`）。`x - 1` 会将最低位的 $1$ 变成 $0$，并将它后面的 $0$ 全变成 $1$（如 $7$ 是 `0111`）。两者做 `&` 运算必定为 $0$。

**2. 提取最低位的 1 (Lowbit)**
- **公式**：`x & -x`  
    
- **原理**：计算机中使用补码存储负数，`-x` 相当于 `~x + 1`。这会导致 `x` 中最低位的 $1$ 保持不变，而其左边的所有位都与原数相反。
    
- **应用**：树状数组（Fenwick Tree）的核心操作。

**3. 清除最低位的 1**
- **公式**：`x = x & (x - 1)` 
    
- **应用**：Brian Kernighan 算法，用于快速统计一个数二进制中 $1$ 的个数（循环执行直到 $x=0$，执行次数即为 $1$ 的个数）。  

**4. 快速奇偶判断与乘除法**

- **奇偶判断**：`x & 1`（结果为 $1$ 是奇数，为 $0$ 是偶数，比 `x % 2 == 0` 快且无视负数符号问题）。 
    
- **乘除 2 的幂**：`x << k` 等价于 $x \times 2^k$；`x >> k` 等价于 $\lfloor x / 2^k \rfloor$。

### 二、 异或（XOR）的神奇性质

异或运算（$\oplus$）常被称为“不进位加法”，在博弈论（如 Nim 游戏）和数据恢复中极度重要。

**1. 自然数异或和的周期性质**

记 $f(n) = 0 \oplus 1 \oplus 2 \dots \oplus n$，它具有以 $4$ 为周期的规律：

- 若 $n \pmod 4 = 0$，则 $f(n) = n$
    
- 若 $n \pmod 4 = 1$，则 $f(n) = 1$  
    
- 若 $n \pmod 4 = 2$，则 $f(n) = n + 1$  
    
- 若 $n \pmod 4 = 3$，则 $f(n) = 0$  
    
- **进阶用法**：求任意区间 $[L, R]$ 的异或和，只需计算 $f(R) \oplus f(L - 1)$。

**2. 消除成对出现的元素**

- **性质**：$x \oplus x = 0$，$x \oplus 0 = x$。
    
- **应用**：数组中除了一个数字出现奇数次，其余全出现偶数次，求该数字。直接把所有数字异或起来，结果就是那个数字。
    

**3. 交换两个变量（无需借助中间变量）**

- **代码**：`a ^= b; b ^= a; a ^= b;`（注意：在同一个数组中操作时，若索引相同会导致元素被清零，需加判断）。

### 三、 状态压缩 DP 中的神仙操作

在状压 DP 中，整数的二进制位被用来表示集合（$1$ 表示在集合内，$0$ 表示不在）。

**1. 枚举子集（极其重要）**

给定一个集合的状态 `mask`，如何高效地枚举它的所有非空子集？

C++

```C++
for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
    // 处理子集 sub
}
```

- **原理**：`sub - 1` 会把最低位的 $1$ 变成 $0$，并将后面的 $0$ 变 $1$，然后 `& mask` 可以把不属于原集合的元素直接剔除，从而精准跳到下一个有效的子集。
    
- **复杂度**：若对 $0 \dots 2^n-1$ 的所有状态都枚举子集，总时间复杂度是 $O(3^n)$，而不是 $O(4^n)$。
    

**2. 集合的常用运算**

- **交集**：`A & B`
    
- **并集**：`A | B`
    
- **差集**：`A & (~B)`（属于 A 但不属于 B）
    
- **对称差**：`A ^ B`（只属于其中一个集合的元素）
    
- **判断 B 是否为 A 的子集**：`(A & B) == B` 或 `(A | B) == A`
    

**3. Gosper's Hack（枚举大小为 k 的子集）**

如何在 $n$ 个元素中，高效按字典序枚举所有包含 $k$ 个元素的集合？

C++

```C++
int limit = (1 << n);
int mask = (1 << k) - 1; // 初始状态，最低的 k 位为 1
while (mask < limit) {
    // 处理当前的 mask
    int c = mask & -mask;
    int r = mask + c;
    mask = (((r ^ mask) >> 2) / c) | r;
}
```

### 四、 GCC 编译器内置函数（竞赛必备）

在 C++ 算法竞赛中，合理使用 GCC 提供的 `__builtin` 系列函数不仅代码短，而且常数极小（通常会被编译成单条汇编指令）。

- **`__builtin_popcount(x)`**：返回 $x$ 在二进制下 $1$ 的个数。
    
- **`__builtin_ctz(x)`**：Count Trailing Zeros，返回二进制下末尾连续 $0$ 的个数（即最低位 $1$ 的位置索引，从 $0$ 开始）。若输入 $0$，行为未定义。
    
- **`__builtin_clz(x)`**：Count Leading Zeros，返回二进制下前导 $0$ 的个数。
    
- **`std::__lg(x)`**：计算 $\lfloor \log_2 x \rfloor$（底层就是用 `clz` 实现的，极为高效的求二进制最高位的方法）。
    

> **注意**：如果处理 64 位整数（`long long`），需要在函数后加 `ll`，如 `__builtin_popcountll(x)`。

### 五、 结合数据结构与进阶算法

**1. 0-1 Trie (字典树)**

- **场景**：解决“给定一个数组，找两数异或值最大/最小”等区间异或极值问题。
    
- **核心**：将数字的二进制形式补齐后当作长度为 30（或 60）的字符串插入 Trie 树中。查询时，利用贪心策略：为了使异或值最大，总是优先走向与当前位相反的子节点。
    

**2. 线性基 (Linear Basis)**

- **场景**：解决子集异或和的相关问题（如求数组的所有子集中，异或和的最大值、第 K 大值、是否存在某种异或和）。
    
- **核心**：将一组数压缩成最多 $\lceil \log_2 M \rceil$ 个数（基底），这些基底的异或空间与原数组完全相同。构造方法类似于高斯消元。
