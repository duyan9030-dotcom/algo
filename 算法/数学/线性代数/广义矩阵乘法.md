在算法竞赛（如 Codeforces、Luogu）中，广义矩阵乘法几乎总是和**矩阵快速幂**绑定在一起出现。它的核心作用是将一类**状态转移代价为线性加减或最值操作**的动态规划（DP）问题，从 $O(N \cdot K)$ 的递推复杂度优化到 $O(N^3 \log K)$。

这里为你详细拆解竞赛中最常考的 **Min-Plus（最小-加法）矩阵乘法**，从理论到代码模板全面解析。
### 一、 为什么能用矩阵快速幂？（核心原理）

普通矩阵快速幂能用来加速斐波那契数列或路径计数，是因为普通矩阵乘法满足**结合律**：$(A \times B) \times C = A \times (B \times C)$。

有了结合律，我们才能计算 $A^{10}$ 时，先算 $A^5 \times A^5$，从而把 $O(K)$ 次乘法优化到 $O(\log K)$ 次。

在 Min-Plus 广义矩阵乘法中：

- **乘法换成加法**（路径长度相加）  
    
- **加法换成取最小值**（取最短路）  
    
- 公式：$C_{i,j} = \min_{k} (A_{i,k} + B_{k,j})$  

**结合律依然成立的根本原因在于分配律**。在常规代数中 $a \times (b + c) = a \times b + a \times c$。而在 Min-Plus 代数中，$+$ 对 $\min$ 也满足分配律：
$$a + \min(b, c) = \min(a+b, a+c)$$

这就是广义矩阵乘法能在算法竞赛中“合法”使用快速幂的数学底座。
### 二、 极其关键的“单位矩阵”重定义

在使用普通矩阵快速幂时，初始的答案矩阵 $res$ 会被设为**单位矩阵 $I$**（主对角线为 1，其余为 0），因为普通乘法中 $1$ 是乘法幺元，$0$ 是加法幺元。

在广义矩阵中，幺元发生了变化，这是无数人初学时最容易写错的坑：

1. **“加法”（即取 $\min$ 操作）的幺元是 $\infty$**：因为 $\min(x, \infty) = x$。所以矩阵的非对角线元素必须初始化为 $\infty$。
    
2. **“乘法”（即 $+$ 操作）的幺元是 $0$**：因为 $x + 0 = x$。所以矩阵的主对角线元素必须初始化为 $0$。

**结论**：Min-Plus 的单位矩阵，其**主对角线全为 $0$，其余元素全为 $\infty$**。

### 三、 经典竞赛模型：定长最短路

**问题描述**：

给定一张 $N$ 个点、$M$ 条边的有向带权图（$N \le 100$）。求从起点 $S$ 到终点 $T$，**恰好经过 $K$ 条边**的最短路径长度（$K \le 10^9$）。

**DP 视角分析**：

设 $dp[k][i][j]$ 表示从 $i$ 到 $j$ 恰好经过 $k$ 条边的最短路。

状态转移方程：

$$dp[k][i][j] = \min_{1 \le x \le N} \{ dp[k-1][i][x] + W[x][j] \}$$

其中 $W$ 是图的邻接矩阵（如果不连通则 $W[x][j] = \infty$）。

你会发现，这个 DP 的转移方程与 Min-Plus 矩阵乘法公式**完全一致**！

因此，我们可以把邻接矩阵 $W$ 看作初始状态（恰好经过 1 条边的最短路）。

要求经过 $K$ 条边的最短路，本质上就是**求广义矩阵 $W$ 的 $K$ 次方**。

答案即为 $(W^K)_{S, T}$。复杂度从暴力 DP 的 $O(N^3 \cdot K)$ 降维打击为 $O(N^3 \log K)$。
### 四、 C++ 实战代码模板

这是一个标准的、可直接在竞赛中使用的广义矩阵模板（以 Min-Plus 为例）。


C++

```C++
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

const long long INF = 1e18; // 必须足够大，且两个 INF 相加不能溢出 long long

struct Matrix {
    int n;
    vector<vector<long long>> mat;

    // 构造函数，默认初始化为无穷大 (即加法幺元)
    Matrix(int n) : n(n), mat(n, vector<long long>(n, INF)) {}

    // 变为单位矩阵
    void make_identity() {
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) {
                mat[i][j] = (i == j) ? 0 : INF;
            }
        }
    }

    // 重载乘法运算符：Min-Plus 广义矩阵乘法
    Matrix operator*(const Matrix& other) const {
        Matrix res(n);
        for (int i = 0; i < n; ++i) {
            for (int k = 0; k < n; ++k) {
                if (mat[i][k] == INF) continue; // 常数优化，剪枝
                for (int j = 0; j < n; ++j) {
                    if (other.mat[k][j] == INF) continue;
                    res.mat[i][j] = min(res.mat[i][j], mat[i][k] + other.mat[k][j]);
                }
            }
        }
        return res;
    }
};

// 矩阵快速幂
Matrix quick_pow(Matrix A, long long k) {
    Matrix res(A.n);
    res.make_identity(); // 初始为单位矩阵
    
    while (k > 0) {
        if (k & 1) res = res * A;
        A = A * A;
        k >>= 1;
    }
    return res;
}

int main() {
    int n = 3; // 节点数
    Matrix W(n);
    // 假设输入图的边... W.mat[u][v] = weight
    // ...
    
    long long K = 1000000000;
    Matrix ans = quick_pow(W, K);
    
    // 输出 0 到 2 恰好经过 K 条边的最短路
    cout << ans.mat[0][2] << endl;
    return 0;
}
```

### 五、 竞赛常见变体与进阶技巧

#### 1. 求“最多”经过 $K$ 条边的最短路（而非“恰好”）

**技巧：原地自环**

如果是求 $\le K$ 条边的最短路，只需在初始邻接矩阵 $W$ 中，强制令所有主对角线元素 $W[i][i] = \min(W[i][i], 0)$。

这意味着允许在某个节点“原地停留”（即走一条权值为 0 的边），从而消耗掉多余的步数。然后再求 $W^K$ 即可。

#### 2. Max-Plus 矩阵乘法

- **应用场景**：求图中恰好经过 $K$ 条边的**最长路径**（例如树上的 DP 转移被拓展到带环图中，求最大收益）。
    
- **修改点**：把 `min` 改成 `max`，把 `INF` 改成 `-INF`。单位矩阵的主对角线依然是 $0$，其余是 `-INF`。  
#### 3. 边权作为矩阵维度的降维打击（拆点技巧）

有时候题目给的是 $N$ 很大，但**边权非常小**（比如边权只有 $1 \dots 9$）。这不适合直接用矩阵快速幂。

此时经典的套路是把一个点拆成 9 个状态（表示距离到达该点还有 1~9 的距离），将带权图转化为**边权仅为 1 的无权图**。然后在无权图上做普通的矩阵乘法（Boolean 乘法或普通乘法求方案数）。这种题往往结合广义矩阵和拆点图论一起考察。
