康托展开（Cantor Expansion）本质上是一个**双射函数**，它建立了一个 $1 \sim n$ 的全排列与其在所有排列中的**字典序排名**之间的映射关系。它可以解答这样一个问题：“给出一个全排列，它在所有全排列中排第几？”

## 数学公式

康托展开的公式为：

$$X = a_n(n-1)! + a_{n-1}(n-2)! + \dots + a_1 \cdot 0!$$

- **$X$**：代表在字典序中，**严格小于**当前排列的排列总数。因此当前排列的实际排名是 $X + 1$。
    
- **$a_i$**：表示在当前元素的右侧，有几个数比当前元素小（等价于：在剩下的可用数字中，有几个比当前元素小）。

## 核心思想解析

这个公式背后是基础的组合数学原理。假设我们有一个排列，从左往右看每一个位置：

如果我们在这个位置上，不放当前真实的数字，而是从**还没用过且比它小**的数字里挑一个放上去，那么无论后面的数字怎么排，整个排列的字典序一定比真实的排列小。

既然第一位固定了一个更小的数，后面还剩下 $k$ 个位置，那么后面的排法就有 $k!$ 种。把每个位置产生的分支累加起来，就是比当前排列小的排列总数。

## 计算示例

以 $n=5$ 的排列 **[3, 4, 1, 5, 2]** 为例，计算它在 $1, 2, 3, 4, 5$ 的所有全排列中的排名：

1. **第 1 位是 3**：
    
    比 3 小且还没用过的数有 2 个（1 和 2）。
    
    如果这一位放 1 或 2，后面 4 个位置可以随便排。
    
    产生的分支数：$2 \times 4! = 48$
    
2. **第 2 位是 4**：
    
    比 4 小且还没用过的数有 2 个（1 和 2，注意 3 已经用过了）。
    
    如果这一位放更小的数，后面 3 个位置随便排。
    
    产生的分支数：$2 \times 3! = 12$
    
3. **第 3 位是 1**：
    
    比 1 小且还没用过的数有 0 个。
    
    产生的分支数：$0 \times 2! = 0$
    
4. **第 4 位是 5**：
    
    比 5 小且还没用过的数有 1 个（2）。
    
    产生的分支数：$1 \times 1! = 1$
    
5. **第 5 位是 2**：
    
    比 2 小且还没用过的数有 0 个。
    
    产生的分支数：$0 \times 0! = 0$
    

将所有分支数累加：$X = 48 + 12 + 0 + 1 + 0 = 61$。

说明有 61 个排列比 [3, 4, 1, 5, 2] 小。因此它的排名是 **第 62 名**。

## 逆康托展开

因为康托展开是一个双射，所以它可以反过来用：**已知排名，求对应的全排列**。

计算方法就是不断对阶乘进行**除法取商和取余**：

例如，求 $n=5$ 的第 62 名排列（即 $X = 61$）：

1. $61 \div 4! = 61 \div 24 = 2 \dots 13$。商为 2，说明第 1 位要取可用数字中第 3 小的数（索引为 2 的数，即 **3**）。
    
2. 用余数 13 接着算：$13 \div 3! = 13 \div 6 = 2 \dots 1$。商为 2，取剩下可用数字（1, 2, 4, 5）中第 3 小的数（即 **4**）。
    
3. 余数 1：$1 \div 2! = 0 \dots 1$。商为 0，取剩下（1, 2, 5）中第 1 小的数（即 **1**）。
    
4. 余数 1：$1 \div 1! = 1 \dots 0$。商为 1，取剩下（2, 5）中第 2 小的数（即 **5**）。
    
5. 余数 0：直接取最后一个剩下的数（即 **2**）。
    
    得出排列：**[3, 4, 1, 5, 2]**。

```C++
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;
const int mod = 998244353;
const ll INF = -1e18;
ll n, ans = 0;
ll a[1000005], k[1000005];
ll tree[1000005];
ll lowbit(ll x)
{
    return x & -x;
}
void add(ll i, ll x)
{
    while (i <= n)
    {
        tree[i] += x;
        i += lowbit(i);
    }
}
ll query(ll i)
{
    ll sum = 0;
    while (i > 0)
    {
        sum += tree[i];
        i -= lowbit(i);
    }
    return sum;
}
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    k[0] = 1;
    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
        add(i, 1);
        k[i] = (i * k[i - 1]) % mod;
    }
    for (int i = 1; i <= n; i++)
    {
        add(a[i], -1);
        ll sum = query(a[i]);
        // cout << sum << endl;
        ans = (ans + sum * k[n - i]) % mod;
    }
    cout << ans + 1 << '\n';
    return 0;
}
```
