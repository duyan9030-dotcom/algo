单链表（Singly Linked List）是一种链式存取的数据结构。它的数据在内存中**不需要连续存放**，而是由一系列在内存中随机分布的“节点”组成。每个节点包含两部分：存放实际数据的**数据域**，以及存放下一个节点内存地址的**指针域**。
  
单链表的核心优势在于**动态扩展和高效的局部插入/删除**，但代价是失去了数组那样的随机访问能力。

以下是使用 C 语言（指针 + 结构体）实现的单链表详解与核心操作代码。

## 1. 结构体与指针定义

单链表的基本单位是节点（Node）。我们使用 `struct` 来定义它，并通过指针将其串联。

  

C

```C++
#include <stdio.h>
#include <stdlib.h>

// 定义链表节点结构体
typedef struct Node {
    int data;           // 数据域：存储当前节点的数据
    struct Node* next;  // 指针域：存储下一个节点的地址
} Node;

// 创建新节点的辅助函数
Node* createNode(int data) {
    Node* newNode = (Node*)malloc(sizeof(Node)); // 动态分配内存
    if (newNode == NULL) {
        printf("内存分配失败！\n");
        return NULL;
    }
    newNode->data = data;
    newNode->next = NULL; // 新节点的下一个指针默认置空
    return newNode;
}
```

## 2. 核心操作实现

### 头插法 (Insert at Head)

将新节点直接插入到链表的最前端。新节点将成为新的“头”。

C

```C++
// 传入头指针的地址（Node**），因为要修改头指针本身的指向
void insertAtHead(Node** head, int data) {
    Node* newNode = createNode(data);
    newNode->next = *head; // 新节点指向原先的头节点
    *head = newNode;       // 头指针更新为新节点
}
```

### 尾插法 (Insert at Tail)

将新节点插入到链表的最后面。需要先遍历找到当前的最后一个节点。

C

```
void insertAtTail(Node** head, int data) {
    Node* newNode = createNode(data);
    
    // 如果链表为空，新节点即为头节点
    if (*head == NULL) {
        *head = newNode;
        return;
    }
    
    // 遍历找到最后一个节点
    Node* temp = *head;
    while (temp->next != NULL) {
        temp = temp->next;
    }
    temp->next = newNode; // 将原尾节点的 next 指向新节点
}
```

### 删除指定值的节点 (Delete by Value)

删除第一次出现的指定数据节点。需要同时追踪“当前节点”和“前驱节点”。

  

C

```
void deleteNode(Node** head, int key) {
    if (*head == NULL) return; // 链表为空

    Node* temp = *head;
    Node* prev = NULL;

    // 情况1：头节点就是要删除的节点
    if (temp != NULL && temp->data == key) {
        *head = temp->next; // 头指针后移
        free(temp);         // 释放内存
        return;
    }

    // 情况2：遍历寻找要删除的节点，并记录前驱节点
    while (temp != NULL && temp->data != key) {
        prev = temp;
        temp = temp->next;
    }

    // 如果没找到该值
    if (temp == NULL) return; 

    // 解除链接并释放内存
    prev->next = temp->next;
    free(temp);
}
```

### 遍历与打印 (Traversal)

顺着指针依次访问每一个节点，直到遇到 `NULL`。

  

C

```
void printList(Node* head) {
    Node* temp = head;
    while (temp != NULL) {
        printf("%d -> ", temp->data);
        temp = temp->next;
    }
    printf("NULL\n");
}
```

## 3. 各种操作的复杂度分析

链表的性能特点可以概括为：**改动极快，查找很慢**。

  

|**操作**|**时间复杂度**|**空间复杂度**|**说明**|
|---|---|---|---|
|**按索引访问 (Access)**|$O(n)$|$O(1)$|必须从头节点开始，顺着指针逐个往后找，无法像数组一样通过数学计算直接定位（随机访问）。|
|**按值查找 (Search)**|$O(n)$|$O(1)$|需要从头遍历比对每一个节点的数据，最坏情况需要遍历整个链表。|
|**头部插入/删除**|$O(1)$|$O(1)$|只需要修改头指针和第一个节点的 `next` 引用，极快。|
|**尾部插入**|$O(n)$ / $O(1)$|$O(1)$|如果只有头指针，需要 $O(n)$ 遍历到末尾；如果额外维护了一个 `tail` 尾指针，则可优化至 $O(1)$。|
|**中间已知节点后插入**|$O(1)$|$O(1)$|只要已经获取了目标节点的指针，执行插入仅需改变两次指针指向，不需要移动其他数据。|
|**删除中间指定节点**|$O(n)$|$O(1)$|删除操作本身仅需 $O(1)$，但为了完成删除，必须先用 $O(n)$ 的时间找到它的**前驱节点**。|

> **内存分配的代价：** 频繁进行 `malloc` 和 `free` 会产生内存碎片，并且系统调用的开销较大。在对性能极其敏感的场景（如算法竞赛或内核级开发）中，有时会改用“数组模拟链表（静态链表）”来替代结构体和指针。
