线段树（Segment Tree）是一种基于分治思想的二叉树数据结构，主要用于在 $O(\log N)$ 的时间复杂度内处理动态的区间查询（Range Query）**和**区间修改（Range Update）问题。

## 原理与结构

线段树的本质是将一个长度为 $N$ 的数组（或区间）不断二分，直到分割成长度为 $1$ 的单点。树上的每一个节点代表一个区间 $[L, R]$ 的某种统计信息（如区间和、最大值等）。

1. **节点定义**：根节点代表整个区间 $[1, N]$。
    
2. **递归划分**：对于任意一个代表区间 $[L, R]$ 的节点（其中 $L < R$），令 $mid = \lfloor \frac{L+R}{2} \rfloor$，则其左子节点代表区间 $[L, mid]$，右子节点代表区间 $[mid+1, R]$。 
    
3. **叶子节点**：当 $L = R$ 时，节点为叶子节点，代表原数组中的单个元素。
    
4. **懒惰标记（Lazy Propagation）**：为了支持高效的区间修改，线段树引入了“懒惰标记”。当修改一个完整的区间时，不继续向下更新其子节点，而是给当前节点打上一个标记（Lazy Tag），表示“该区间的所有子节点都需要进行某种修改，但暂时不执行”。只有当后续查询或修改需要访问这些子节点时，才将标记**下放（Push-down）**，从而将区间修改的时间复杂度也降至 $O(\log N)$。

## 可以维护什么样的数据

线段树可以维护任何满足结合律（Associativity）的数据。即对于操作 $\oplus$，必须满足 $(A \oplus B) \oplus C = A \oplus (B \oplus C)$。
- **完美支持（支持区间修改与查询）**：
    
    - **区间和（Sum）**：父节点值 = 左子节点 + 右子节点。加上 Lazy Tag 时，子节点新增的值为 `标记值 * 区间长度`。  
        
    - **最值（Max / Min）**：父节点值 = $\max($左子节点, 右子节点$)$。  
        
    - **按位操作（AND / OR / XOR）**：满足结合律。  
        
    - **最大公约数 / 最小公倍数（GCD / LCM）**：支持单点修改和区间查询。区间修改如果是一般的加减法较难处理，但如果是覆盖修改则可以。
        
    - **矩阵乘法**：常用于维护线性递推式或动态规划的状态转移。
        
- **难以直接维护（通常需要高级变种或其他数据结构）**：
      
    - **众数（Mode） / 中位数（Median）**：不满足结合律，合并两个区间的众数/中位数无法在 $O(1)$ 内完成（通常需要主席树或莫队算法）。

## 代码实现（C++ 区间加法 + 区间求和）

以下是使用数组模拟指针的线段树标准模板（空间开 $4N$）。

C++

```C++
#include <vector>
using namespace std;

class SegmentTree {
private:
    vector<long long> tree, lazy;
    int n;

    // 向上合并，用子节点信息更新当前节点
    void push_up(int rt) {
        tree[rt] = tree[rt * 2] + tree[rt * 2 + 1];
    }

    // 向下传递懒惰标记
    void push_down(int rt, int l, int r) {
        if (lazy[rt] != 0) {
            int mid = l + (r - l) / 2;
            // 更新左子节点
            tree[rt * 2] += lazy[rt] * (mid - l + 1);
            lazy[rt * 2] += lazy[rt];
            // 更新右子节点
            tree[rt * 2 + 1] += lazy[rt] * (r - mid);
            lazy[rt * 2 + 1] += lazy[rt];
            // 清空当前节点标记
            lazy[rt] = 0;
        }
    }

public:
    SegmentTree(int size) {
        n = size;
        tree.assign(4 * n + 1, 0);
        lazy.assign(4 * n + 1, 0);
    }

    // 建树
    void build(int rt, int l, int r, const vector<long long>& arr) {
        if (l == r) {
            tree[rt] = arr[l];
            return;
        }
        int mid = l + (r - l) / 2;
        build(rt * 2, l, mid, arr);
        build(rt * 2 + 1, mid + 1, r, arr);
        push_up(rt);
    }

    // 区间修改：[L, R] 加上 val
    void update(int rt, int l, int r, int L, int R, long long val) {
        if (L <= l && r <= R) {
            tree[rt] += val * (r - l + 1);
            lazy[rt] += val;
            return;
        }
        push_down(rt, l, r);
        int mid = l + (r - l) / 2;
        if (L <= mid) update(rt * 2, l, mid, L, R, val);
        if (R > mid)  update(rt * 2 + 1, mid + 1, r, L, R, val);
        push_up(rt);
    }

    // 区间查询：求 [L, R] 的和
    long long query(int rt, int l, int r, int L, int R) {
        if (L <= l && r <= R) {
            return tree[rt];
        }
        push_down(rt, l, r);
        int mid = l + (r - l) / 2;
        long long res = 0;
        if (L <= mid) res += query(rt * 2, l, mid, L, R);
        if (R > mid)  res += query(rt * 2 + 1, mid + 1, r, L, R);
        return res;
    }
};
```

## 复杂度证明

### 1. 空间复杂度：$O(N)$

线段树是一棵满二叉树（如果不满，底层会有空缺，但数组依然要按满二叉树分配）。

对于长度为 $N$ 的数组，树的深度 $k = \lceil \log_2 N \rceil + 1$。

一棵深度为 $k$ 的满二叉树最多有 $2^k - 1$ 个节点。

因为 $2^{\lceil \log_2 N \rceil} < 2N$，所以总节点数 $< 2 \times 2N = 4N$。

**结论**：线段树需要开 $4N$ 大小的数组，空间复杂度为 $O(N)$。

### 2. 时间复杂度：$O(\log N)$

- **建树（Build）**：$O(N)$。树上每个节点被访问一次且只计算一次 $O(1)$ 的状态转移，总节点数约为 $2N$，故时间为 $O(N)$。
    
- **区间查询/修改（Query / Update）**：$O(\log N)$。
    
    **证明**：当查询或修改目标区间 $[L, R]$ 时，线段树在同一层最多只会访问 **4个节点**。
    
    假设某一层我们访问了 $\ge 5$ 个节点，因为这 $5$ 个节点是连续的，中间的 $3$ 个节点必然互为兄弟节点，即至少有一对兄弟节点同属一个父节点。
    
    根据线段树的逻辑，如果一对兄弟节点的区间都完全包含在目标区间 $[L, R]$ 内，我们在上一层就会直接处理它们的父节点，而**不会递归到这一层**。
    
    因此，在树的任意一层，递归展开的节点边界数量常数级受限（最多 $4$ 个）。树的高度是 $O(\log N)$，每一层的操作是 $O(1)$，总时间复杂度即为 $O(\log N)$。
    

## 使用场景

1. **动态 RMQ 问题（Range Minimum/Maximum Query）**
    
    当数组需要频繁修改（单点或区间），并且需要频繁查询任意区间的最大值或最小值时，线段树是最优选。 
    
2. **扫描线算法（Sweep-Line）**
    
    在计算几何中求矩形面积并、周长并时，将坐标轴离散化后，使用线段树维护扫描线在某个坐标上的覆盖长度。
    
3. **树上问题（结合树链剖分）**
    
    通过重链剖分（Heavy-Light Decomposition），将树上的路径转化为一维数组上的连续区间，再用线段树进行 $O(\log^2 N)$ 的路径修改和查询。  
    
4. **求逆序对 / 计数问题**
    
    动态维护一个值域数组，查询值域区间内的元素个数（权值线段树）。也可以用来快速查找数组中第 $K$ 大的元素。
    
5. **维护复杂连通性或几何信息**
    
    例如维护区间最大连续子段和（需要同时维护区间总和、最大前缀和、最大后缀和、最大子段和），这也是线段树高度可定制化的体现。
