前置知识：[[二叉树]] 

堆（Heap）本质上是一种**完全二叉树**（Complete Binary Tree），通常使用数组来进行存储和表示。根据节点之间的相对大小关系，堆被划分为**大根堆（Max-Heap）**和**小根堆（Min-Heap）**。
![[Pasted image 20260930200037.png]]
### 一、 大根堆与小根堆的原理

1. **结构特性**：因为是完全二叉树，如果将元素按层序遍历存放在以 `1` 开始的数组中，对于任意节点 $i$，其左子节点为 $2i$，右子节点为 $2i+1$，父节点为 $i/2$。
    
2. **大根堆（Max-Heap）**：任意一个父节点的值**大于或等于**其左右子节点的值。也就是说，**堆顶（根节点）是整个堆中的最大值**。
    
3. **小根堆（Min-Heap）**：任意一个父节点的值**小于或等于**其左右子节点的值。也就是说，**堆顶（根节点）是整个堆中的最小值**。

**核心操作原理：**

- **插入元素 (Push / 向上调整 Up)**：将新元素放到数组的最后一个位置。然后将其与父节点比较，如果破坏了堆的性质（例如大根堆中比父节点大），则与父节点交换，一路向上“上浮”，直到满足性质为止。时间复杂度 $O(\log N)$。
    
- **删除堆顶 (Pop / 向下调整 Down)**：将堆顶元素（最大或最小值）弹出，然后将数组**末尾**的元素放到堆顶位置。接着将该节点与其左右子节点比较，选择较大（大根堆）或较小（小根堆）的子节点进行交换，一路“下沉”，直到满足性质。时间复杂度 $O(\log N)$。

### 二、 堆的作用 (应用场景)

1. **优先队列（Priority Queue）**：堆是实现优先队列的最佳数据结构。操作系统任务调度、Dijkstra求最短路等都依赖优先队列。
    
2. **Top-K 问题**：
    
    - 求海量数据中**最大的 K 个数**：维护一个大小为 K 的**小根堆**。遇到比堆顶大的数，替换堆顶并向下调整。
        
    - 求海量数据中**最小的 K 个数**：维护一个大小为 K 的**大根堆**。
        
3. **堆排序（Heap Sort）**：利用堆可以在 $O(1)$ 时间内拿到极值的特性，不断取出堆顶并调整，可以实现 $O(N \log N)$ 且空间复杂度 $O(1)$ 的排序。

### 三、 代码实现 1：手写堆

手写堆在算法竞赛中很常见，因为它执行常数极小，速度比 STL 快，且能灵活修改内部元素。以下为一个**手写大根堆**的实现：

```C++
#include <stdio.h>

#define MAX_SIZE 1000 // 定义堆的最大容量

// 全局静态数组和元素数量
int heap[MAX_SIZE + 1]; 
int heap_size = 0;      

// 初始化/清空堆
void initHeap() {
    heap_size = 0; 
}

// 交换堆中两个位置的元素（传入下标代替指针）
void swap_elements(int i, int j) {
    int temp = heap[i];
    heap[i] = heap[j];
    heap[j] = temp;
}

// 向上调整 (插入元素时使用)
void shiftUp(int index) {
    // 当还没到达根节点，且当前节点大于其父节点时
    while (index > 1 && heap[index] > heap[index / 2]) {
        swap_elements(index, index / 2); // 通过下标交换
        index /= 2;                      // 更新索引为父节点
    }
}

// 向下调整 (删除堆顶时使用)
void shiftDown(int index) {
    while (index * 2 <= heap_size) {
        int left = index * 2;
        int right = index * 2 + 1;
        int max_child = left;

        // 如果有右子节点，且右子节点大于左子节点，将最大子节点更新为右子节点
        if (right <= heap_size && heap[right] > heap[left]) {
            max_child = right;
        }

        // 如果当前节点已经大于等于最大的子节点，调整结束
        if (heap[index] >= heap[max_child]) {
            break;
        }

        swap_elements(index, max_child); // 通过下标交换
        index = max_child;
    }
}

// 插入元素
void push(int val) {
    if (heap_size >= MAX_SIZE) {
        printf("Error: Heap is full!\n");
        return;
    }
    
    heap_size++;                   // 增加元素个数
    heap[heap_size] = val;         // 将新元素放到数组末尾
    shiftUp(heap_size);            // 向上调整
}

// 弹出堆顶
void pop() {
    if (heap_size == 0) return; // 空堆直接返回
    
    swap_elements(1, heap_size); // 将末尾元素交换到堆顶
    heap_size--;                 // 元素个数减一 (相当于删除了原堆顶)
    
    if (heap_size > 0) {
        shiftDown(1);            // 将新的堆顶向下调整
    }
}

// 获取堆顶元素
int top() {
    if (heap_size > 0) {
        return heap[1];
    }
    return -1; // 异常情况返回 -1
}

// 判断堆是否为空 (返回 1 表示空，0 表示非空)
int empty() {
    if (heap_size == 0) {
        return 1;
    }
    return 0;
}

// ================== 测试代码 ==================
int main() {
    initHeap(); // 初始化全局变量

    // 插入测试数据
    push(10);
    push(50);
    push(30);
    push(90);
    push(20);

    // 预期弹出顺序：90 -> 50 -> 30 -> 20 -> 10
    printf("Max Heap elements in order:\n");
    while (empty() == 0) {
        printf("%d ", top());
        pop();
    }
    printf("\n");

    return 0;
}
```

### 四、 代码实现 2：C++ STL 库及重载运算符的使用

在工程代码中，一般直接使用 `<queue>` 头文件中的 `std::priority_queue`。

**避坑指南**：C++ STL 中的优先队列**默认是大根堆**。

#### 1. 基础数据类型的调用

C++

```C++
#include <iostream>
#include <queue>
#include <vector>

using namespace std;

int main() {
    // 1. 默认声明：大根堆 (Max-Heap)
    priority_queue<int> maxHeap;
    
    // 2. 声明小根堆 (Min-Heap)：需要多传两个模板参数
    priority_queue<int, vector<int>, greater<int>> minHeap;
}
```

#### 2. 自定义结构体与重载运算符

当我们想把自定义的结构体（例如带有距离和坐标的节点）放入堆中时，必须告诉 STL 它们之间如何比较。

**核心逻辑：** STL 中的 `priority_queue` 在比较 `a` 和 `b` 时，默认使用 `a < b`。

如果 `a < b` 返回 `true`，优先队列会认为 `a` 的优先级**更低**，从而把 `a` 往下沉，把 `b` 往上浮。

- **实现大根堆**：重载 `<` 运算符时，按照**正常**的逻辑写（小就是小）。
    
- **实现小根堆**：重载 `<` 运算符时，把逻辑**反向**（让较小的值被判定为“较大/优先级更低”），这样小的值才会浮到堆顶。

C++

```C++
#include <iostream>
#include <queue>
#include <string>

using namespace std;

// === 场景 A：自定义大根堆 ===
struct MaxNode {
    int id;
    int score;
    
    // 重载小于号 <
    bool operator<(const MaxNode& other) const {
        // 正常逻辑：如果自己的分数小于别人的分数，返回 true
        // 这样分数大的优先级高，浮在上面，形成大根堆
        return this->score < other.score; 
    }
};

// === 场景 B：自定义小根堆 ===
struct MinNode {
    int id;
    int cost;
    
    // 重载小于号 < (注意逻辑反转)
    bool operator<(const MinNode& other) const {
        // 反向逻辑：如果自己的代价大于别人的代价，返回 true
        // 这样 STL 认为代价大的是“弱者”把它往下沉，代价小的浮在上面，形成小根堆
        return this->cost > other.cost; 
    }
};

int main() {
    // 大根堆测试
    priority_queue<MaxNode> maxQ;
    maxQ.push({1, 50});
    maxQ.push({2, 90});
    maxQ.push({3, 70});
    cout << "Max-Heap Top ID: " << maxQ.top().id << " (Score: " << maxQ.top().score << ")" << endl;
    // 输出: Max-Heap Top ID: 2 (Score: 90)

    // 小根堆测试 (常用于 Dijkstra 最短路算法)
    priority_queue<MinNode> minQ;
    minQ.push({1, 50});
    minQ.push({2, 90});
    minQ.push({3, 70});
    cout << "Min-Heap Top ID: " << minQ.top().id << " (Cost: " << minQ.top().cost << ")" << endl;
    // 输出: Min-Heap Top ID: 1 (Cost: 50)

    return 0;
}
```

> **补充：另一种重载写法（仿函数 / 函数对象）**
> 
> 如果不想修改结构体内部（比如结构体是第三方库提供的），可以单独写一个比较结构体：
> 
> C++
> 
> ```
> struct Cmp {
>     bool operator()(const Node& a, const Node& b) {
>         return a.cost > b.cost; // 小根堆逻辑
>     }
> };
> priority_queue<Node, vector<Node>, Cmp> pq;
 ```
