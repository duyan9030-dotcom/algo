前置知识：[[二叉树]]

并查集（Disjoint Set Union，简称 DSU 或 Union-Find）是一种用于管理元素分组的树形数据结构。它不仅空间复杂度低，而且在进行了优化后，几乎可以实现常数时间级别的查询和合并操作。

## 一、 并查集的原理

并查集的核心思想是用“树”**来表示一个集合，树的根节点就是这个集合的**“代表元”。如果两个元素的根节点相同，说明它们属于同一个集合。

它主要支持三个核心操作：

1. **初始化（Init）：** 开始时，每个元素各自构成一个独立的集合，即每个元素的父节点指向自己。
    
2. **查找（Find）：** 顺着父节点指针一直向上找，直到找到根节点（父节点是自己的节点）。这个过程用于判断某个元素属于哪个集合。
    
3. **合并（Union）：** 找到两个元素的根节点，如果根节点不同，则让其中一个根节点成为另一个根节点的子节点，从而将两个集合连成一个。

## 二、 并查集的作用

并查集主要用于处理**动态连通性**问题，即快速判断两个元素是否在同一个集合中，或者将两个集合合并。常见应用场景包括：

- **网络连通性：** 判断社交网络中的两人是否间接认识，或计算机网络中的两台机器是否连通。
    
- **图论算法：** 在 Kruskal 算法中用于寻找最小生成树，快速判断新加入的边是否会与已有的边构成环。
    
- **无向图找环：** 遍历无向图的边，如果某条边的两个端点已经属于同一个集合，说明图中存在环。
    
- **等价类划分：** 比如处理变量之间的等式与不等式关系。

## 三、 两种核心优化

如果树退化成一条链，每次 `Find` 操作的时间复杂度会退化为 $O(N)$。为了避免这种情况，我们必须引入两种优化，将其时间复杂度降至 $O(\alpha(N))$（$\alpha$ 为反阿克曼函数，在宇宙数量级内 $\alpha(N) < 5$，可视为常数）。

### 1. 路径压缩（Path Compression）

**针对 `Find` 操作的优化。**

在执行 `Find` 查找根节点的过程中，既然我们已经遍历了从当前节点到根节点路径上的所有节点，不如**把这条路径上的所有节点直接连接到根节点上**。这样下次查找这些节点时，只需一步就能找到根节点，大幅降低树的高度。

### 2. 按秩合并（Union by Rank / Size）

**针对 `Union` 操作的优化。**

如果把一棵很高的树合并到一棵很矮的树下，会导致新树的高度变高，增加后续查找的成本。按秩合并就是维护一棵树的高度（或节点数量，称为“秩”），在合并时，**永远把秩较小的树的根节点连接到秩较大的树的根节点上**。如果两棵树的秩相等，随便连，并将新根节点的秩加 1。

## 四、 C语言代码实现

下面是同时应用了**路径压缩**和**按秩合并**的完整 C 语言代码实现：

C

```C++
#include <stdio.h>
#include <stdlib.h>

#define MAX_SIZE 1000 // 假设最大有1000个元素

// 全局数组，parent存储父节点，rank_arr存储树的深度（秩）
int parent[MAX_SIZE];
int rank_arr[MAX_SIZE];

// 1. 初始化
void init(int n) {
    for (int i = 0; i < n; i++) {
        parent[i] = i;       // 初始时，每个元素的根节点是自己
        rank_arr[i] = 1;     // 初始时，每棵树的高度（秩）都是1
    }
}

// 2. 查找（带路径压缩）
int find(int x) {
    // 如果自己就是根节点，直接返回
    if (parent[x] != x) {
        parent[x] = find(parent[x]); 
    }
    // 递归查找根节点，并在回溯时将沿途的父节点直接改为根节点（路径压缩）
    return parent[x];
}

// 3. 合并（按秩合并）
void union_sets(int x, int y) {
    int rootX = find(x);
    int rootY = find(y);

    // 如果根节点相同，说明已经在同一个集合中，无需合并
    if (rootX != rootY) {
        // 将高度（秩）较小的树，连接到高度较大的树上
        if (rank_arr[rootX] < rank_arr[rootY]) {
            parent[rootX] = rootY;
        } else if (rank_arr[rootX] > rank_arr[rootY]) {
            parent[rootY] = rootX;
        } else {
            // 如果高度相同，随便挂载，但目标根节点的高度需要加1
            parent[rootY] = rootX;
            rank_arr[rootX]++;
        }
    }
    //以上代码太过繁琐，比赛中可直接写为
    //parent[find(x)]=find(y);
}

// 测试代码
int main() {
    int n = 6; // 6个元素：0到5
    init(n);

    union_sets(0, 1);
    union_sets(1, 2);
    union_sets(3, 4);
    
    printf("元素0和2是否同属一个集合? %s\n", find(0) == find(2) ? "是" : "否");
    printf("元素0和3是否同属一个集合? %s\n", find(0) == find(3) ? "是" : "否");

    // 把两个大集合合并
    union_sets(2, 4);
    printf("合并后，元素0和3是否同属一个集合? %s\n", find(0) == find(3) ? "是" : "否");

    return 0;
}
```
