在算法竞赛中，搜索算法是解决暴力枚举、状态转移和图论问题的基石。核心框架分为深度优先搜索（DFS）与广度优先搜索（BFS）。

## 深度优先搜索 (DFS) 与回溯

DFS 的原理是“不撞南墙不回头”，利用系统调用栈向深处探索状态树，遇到边界或非法状态时进行回溯。

- **核心代码 (C++)**：
    
    C++
    
    ```C++
    void dfs(int u) {
        if (达到目标状态) { 记录答案; return; }
        for (遍历 u 的所有分支 v) {
            if (未访问 v 且状态合法) {
                标记 v;
                dfs(v);
                撤销标记 (回溯);
            }
        }
    }
    ```
    
- **进阶优化**：**剪枝**（可行性与最优性）通过提前排除无效或非最优分支大幅降低复杂度；**记忆化搜索**通过哈希表记录已计算过的状态，将指数级复杂度降为多项式级，是向动态规划过渡的核心。
    

## 广度优先搜索 (BFS) 与层序扩展

BFS 的原理是“由近及远”，利用队列按层级（步数）逐层扩展状态，首次到达目标状态时即为无权图的最短路径。

- **核心代码 (C++)**：
    
    C++
    
    ```C++
    void bfs(int start) {
        queue<int> q;
        q.push(start); 标记 start;
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (遍历 u 的相邻节点 v) {
                if (未访问 v) {
                    标记 v; 记录距离;
                    q.push(v);
                }
            }
        }
    }
    ```
    
- **进阶优化**：**0-1 BFS** 针对边权仅为 $0$ 和 $1$ 的图，使用双端队列（`deque`）将 $0$ 边压入队首、$1$ 边压入队尾；**双向 BFS** 从起点和终点同时扩展，在中间相遇，极大缩小搜索空间。

## 算法的正确性与复杂度证明

- **完备性证明**：若状态空间有限且图连通，DFS 和 BFS 均能遍历所有状态，通过 `visited` 数组保证不重不漏。
    
- **BFS 最优性证明**：基于数学反证法。假设 BFS 首次访问目标节点 $T$ 的路径长度 $d$ 不是最短路，则必存在更短路径 $d' < d$。但 BFS 按层严格单调递增扩展（$1, 2, \dots$），路径长度为 $d'$ 的节点必然在遍历到 $d$ 层之前出队并完成扩展，故首次到达必定是最短路径。
    
- **时间复杂度**：两者在邻接表表示下均为 $O(V + E)$，其中 $V$ 为状态/节点数，$E$ 为转移/边数。
    

## 进阶高阶搜索体系

当状态空间达到指数级且基础剪枝失效时，需引入启发式搜索或重构搜索空间结构：

- **折半搜索 (Meet in the Middle)**：将 $O(2^N)$ 的搜索空间拆半，分别搜索两端后利用哈希或双指针合并，复杂度降至 $O(2^{N/2})$。
    
- **迭代加深搜索 (IDDFS)**：限制 DFS 的最大深度进行搜索，结合了 DFS 省空间和 BFS 求最短路的优点。
    
- __A_ 算法_*：在 BFS 基础上引入优先队列与估价函数 $f(n) = g(n) + h(n)$，优先扩展预期代价最小的节点。
    
- __IDA_ 算法_*：将 A* 的估价函数结合到 IDDFS 的深度限制中进行极致剪枝，是解决复杂状态谜题（如 15 数码）的最优方案。
