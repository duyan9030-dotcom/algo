斐波那契博弈（Fibonacci Nim）是博弈论中一个经典的无偏博弈（Impartial Game）模型。它的核心在于利用斐波那契数列的独特性质以及齐肯多夫定理（Zeckendorf's Theorem）来构建必胜策略。

## 游戏规则

1. 有一堆数量为 $n$ 的石子（$n \ge 2$）。
    
2. 两名玩家轮流取走石子。
    
3. **首回合限制：** 先手在第一次取石子时，至少要取走 1 个，但**不能将其全部取完**（即取石子数 $x_1$ 满足 $1 \le x_1 < n$）。
    
4. **后续限制：** 之后的每一个回合，当前玩家取走的石子数量 $x_i$ 至少为 1，且**最多不能超过上一个玩家刚取走数量的 2 倍**（即 $1 \le x_i \le 2x_{i-1}$）。
    
5. 取走最后一个石子的玩家获胜。

## 核心结论

斐波那契博弈的胜负完全取决于初始石子数 $n$ 是否为斐波那契数：

- **如果 $n$ 是斐波那契数，后手必胜。**
    
- **如果 $n$ 不是斐波那契数，先手必胜。**

_(注：这里的斐波那契数列定义为 $F_1 = 1, F_2 = 2, F_3 = 3, F_4 = 5, F_5 = 8 \dots$)_

## 必胜策略与数学原理

要理解这个结论，必须引入**齐肯多夫定理（Zeckendorf's Theorem）**：

> 任何正整数都可以被唯一地表示为若干个**不连续**的斐波那契数之和。

即对于任意正整数 $n$，存在唯一的分解方式：

$$n = F_{k_1} + F_{k_2} + \dots + F_{k_m}$$

其中 $k_1 > k_2 > \dots > k_m \ge 1$，且对于任意 $i$，有 $k_i - k_{i+1} \ge 2$（即不能取相邻的斐波那契数）。

### 1. 当 $n$ 不是斐波那契数时（先手必胜）

如果 $n$ 不是斐波那契数，我们可以将其进行齐肯多夫分解。

例如，初始有 11 个石子。11 不是斐波那契数，其分解为 $11 = 8 + 3 = F_5 + F_3$。

**先手策略：** 永远取走齐肯多夫分解中**最小的那个斐波那契数**（记作 $F_{k_m}$）。

在上面的例子中，最小的数是 3，所以先手第一次取走 3 个石子。

**为什么这样能必胜？**

先手取走 $F_{k_m}$ 后，剩下的石子数刚好是分解中其余较大的斐波那契数之和。此时轮到后手，后手最多只能取走 $2 \times F_{k_m}$ 个石子。

根据齐肯多夫分解的性质，相邻两项的下标差至少为 2，这意味着倒数第二小的项 $F_{k_{m-1}}$ 至少是 $F_{k_m + 2}$。

而在斐波那契数列中，有一个重要不等式：

$$2 \times F_{k_m} < F_{k_m + 1} < F_{k_{m-1}}$$

这说明，后手能够取的最大数量 $2 \times F_{k_m}$，**绝对不够把下一个斐波那契数 $F_{k_{m-1}}$ 一次性取完**。

这就迫使后手陷入了一个“面对完整的斐波那契数堆、且无法一次取完”的局面（也就是下面要讲的后手必胜局面的镜像），先手只要在后续每一轮中，将剩下的每一个斐波那契数当作一个独立的子游戏，并扮演子游戏里的“后手”，最终就能取走最后一个石子。

### 2. 当 $n$ 是斐波那契数时（后手必胜）

如果 $n$ 本身就是一个斐波那契数（例如 $n = F_k$）。

因为规则限制先手第一次不能全部取完，先手只能取走 $x$ 个石子（$1 \le x < F_k$）。

先手取完后，剩下的石子数为 $F_k - x$。此时可以将剩下的石子看作一个新的局面。通过严密的数学归纳法可以证明：无论先手取多少，由于 $x < F_k$，后手总是能够根据剩下的石子重新计算齐肯多夫分解，并采取上述的“取走最小斐波那契数”的策略，将先手逼入绝境。先手永远无法跨越 2 倍的限制去摸到最后一个石子，后手必胜。

## 算法实现

在算法竞赛或实际编程中，判断先手是否必胜非常简单，只需预处理斐波那契数列并利用哈希表或二分查找判断 $n$ 是否在其中即可。

C++

```C++
#include <iostream>
#include <vector>

using namespace std;

int main() {
    long long n;
    // 预处理斐波那契数列，直到超过可能的最大输入范围
    vector<long long> fib;
    fib.push_back(1);
    fib.push_back(2);
    while (fib.back() <= 1e18) { // 假设 n 最大为 10^18
        fib.push_back(fib[fib.size() - 1] + fib[fib.size() - 2]);
    }

    while (cin >> n && n != 0) {
        bool is_fib = false;
        // 使用二分查找判断 n 是否为斐波那契数
        int left = 0, right = fib.size() - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (fib[mid] == n) {
                is_fib = true;
                break;
            } else if (fib[mid] < n) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        if (is_fib) {
            cout << "Second win" << "\n"; // n 是斐波那契数，后手必胜
        } else {
            cout << "First win" << "\n";  // n 不是斐波那契数，先手必胜
        }
    }
    return 0;
}
```
