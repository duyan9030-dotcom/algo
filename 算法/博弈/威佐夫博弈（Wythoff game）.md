**威佐夫博弈（Wythoff's Game）** 是博弈论中另一款经典的组合游戏，其核心解法与神奇的**黄金分割率**密切相关。

## 游戏规则

1. 有**两堆**物品，数量分别为 $a$ 和 $b$。
    
2. 有两名玩家轮流取物品。
    
3. 每次取物品有两种操作方式：
    
    - **方式一：** 仅从某一堆中取走任意数量的物品（至少取 $1$ 个，最多取光该堆）。
        
    - **方式二：** 同时从两堆中取走**相同数量**的物品（至少各取 $1$ 个）。
        
4. **最后把物品取光的人获胜**（即面临空堆的人失败）。

## 核心原理与奇异局势（必败态）

在威佐夫博弈中，如果两名玩家都采用最优策略，必然存在一些特定的状态，使得**面对这些状态的玩家必败**。这些状态被称为**奇异局势（Cold Positions）**。

我们将两堆物品的数量表示为一个元组 $(a, b)$，并规定 $a \le b$。

前几个奇异局势如下：

- $(0, 0)$：没有物品，面对此状态者直接失败。
    
- $(1, 2)$
    
- $(3, 5)$
    
- $(4, 7)$
    
- $(6, 10)$

仔细观察这些奇异局势，你会发现它们有两个极其重要的性质：

1. **差值递增：** 第 $k$ 个奇异局势的差值恰好为 $k$。例如 $(1, 2)$ 差值为 $1$；$(3, 5)$ 差值为 $2$；$(6, 10)$ 差值为 $4$。
    
2. **包含所有非负整数：** 每一个非负整数都在这些奇异局势中出现且仅出现一次。

这意味着，如果你面对的局势不是奇异局势（即先手必胜态），你总能通过一次合法的操作，将其变成一个奇异局势丢给对手。

## 黄金分割与通项公式

由于上述两个性质，数学家们利用贝蒂定理（Beatty's Theorem）推导出了奇异局势的通项公式。

假设面对的局势是第 $k$ 个奇异局势 $(a_k, b_k)$，且 $a_k \le b_k$，那么：

$$k = b_k - a_k$$

$$a_k = \lfloor k \times \phi \rfloor$$

$$b_k = a_k + k$$

其中，$\lfloor \dots \rfloor$ 表示向下取整，而 $\phi$ 是**黄金分割率**：

$$\phi = \frac{1 + \sqrt{5}}{2} \approx 1.6180339887$$

**胜负判断逻辑：**

给定任意局势 $(a, b)$，且 $a \le b$：

1. 计算两堆物品的差值 $k = b - a$。
    
2. 用差值 $k$ 乘以黄金分割率，并向下取整，得到期望的极小值 $expected\_a = \lfloor k \times \frac{1 + \sqrt{5}}{2} \rfloor$。
    
3. 如果 $expected\_a$ 等于实际的 $a$，说明当前是奇异局势，**后手必胜**。
    
4. 如果不等于，说明不是奇异局势，**先手必胜**。
    

## 演练示例

假设两堆物品数量为 $(4, 7)$。

1. 规定 $a = 4, b = 7$。
    
2. 计算差值 $k = 7 - 4 = 3$。
    
3. 计算期望的 $a$ 值：$3 \times 1.6180339... = 4.854...$，向下取整为 $4$。
    
4. 期望的 $a=4$ 与实际的 $a=4$ 相等。
    
    因此 $(4, 7)$ 是奇异局势，面对这个局势的**先手必败（后手必胜）**。无论先手在一堆中拿多少，或者同时在两堆中拿多少，后手都能将其转化为另一个更小的奇异局势。
    

再假设两堆物品数量为 $(5, 7)$。

1. $a = 5, b = 7$。
    
2. 差值 $k = 7 - 5 = 2$。
    
3. 期望的 $a$ 值为 $\lfloor 2 \times 1.6180339... \rfloor = \lfloor 3.236... \rfloor = 3$。
    
4. 期望的 $3$ 不等于实际的 $5$。
    
    因此 $(5, 7)$ 不是奇异局势，**先手必胜**。
    
    先手的制胜策略是：同时从两堆中取走 $1$ 个物品，把局面变成 $(4, 6)$？不对，$(4, 6)$ 的差值是 $2$，期望值是 $3$，依然不是奇异局势。
    
    正确的操作是：先手从两堆中各取走 $2$ 个物品，将局面变成 $(3, 5)$。由于 $(3, 5)$ 是一个奇异局势，后手接盘必败。
    

## 算法实现

在代码实现时，唯一需要注意的坑是浮点数精度。C++ 中的 `double` 精度通常足够解决绝大部分问题。

C++

```C++
#include <iostream>
#include <cmath>
#include <algorithm>

using namespace std;

// 判断在威佐夫博弈中先手是否必胜
// true: 先手必胜, false: 后手必胜 (即当前为奇异局势)
bool wythoffGame(int a, int b) {
    if (a > b) {
        swap(a, b); // 确保 a <= b
    }
    
    int k = b - a;
    double phi = (1.0 + sqrt(5.0)) / 2.0;
    
    // 计算当前差值 k 对应的奇异局势的第一个值
    int expected_a = (int)(k * phi);
    
    // 如果 a 不等于 expected_a，则是非奇异局势，先手必胜
    return a != expected_a; 
}
```
