尼姆博弈（Nim Game）是最基础、也是最核心的无偏博弈（Impartial Game）模型。它不仅自身有着优美的数学结论，更是所有公平组合游戏（通过 SG 定理）的底层基石。

## 游戏规则

1. 有 $n$ 堆石子，数量分别为 $A_1, A_2, \dots, A_n$。
    
2. 两名玩家轮流行动。
    
3. 每次行动，玩家必须选择**其中一堆**石子，并从中取走**任意正整数**个石子（至少取 1 个，最多可以把这一堆全取走）。
    
4. 最后取走所有石子（让对手无石子可取）的玩家获胜。

## 核心定理（Bouton 定理）

尼姆博弈的胜负完全取决于所有石子堆数量的**按位异或和（Bitwise XOR Sum）**。

我们将初始状态的异或和记为 $S$：

$$S = A_1 \oplus A_2 \oplus \dots \oplus A_n$$

- **如果 $S \neq 0$**：先手必胜（此状态称为 N 态，Next player wins）。
    
- **如果 $S = 0$**：后手必胜（此状态称为 P 态，Previous player wins）。

## 为什么胜负与异或和 (XOR) 有关？

要理解异或和为何能决定胜负，我们需要从博弈论的“状态转移”逻辑来推导。任何一个必胜策略，本质上都是**确保自己始终将必败态（陷阱）交给对手**。

尼姆博弈的结论成立，完全依赖于以下三个层层递进的数学事实：

### 1. 终局状态毫无疑问是 $S = 0$

当游戏结束时，所有的石子都被取光，即每一堆的数量都是 0。

此时异或和 $S = 0 \oplus 0 \dots \oplus 0 = 0$。面对这个局面的玩家无石子可取，判定为输。因此，$S=0$ 是终极的必败态。

### 2. 面对 $S = 0$，任何操作都会导致 $S \neq 0$（必败态无法自救）

假设当前局面异或和 $S = A_1 \oplus A_2 \dots \oplus A_n = 0$。

如果玩家从第 $i$ 堆取走若干石子，使其数量从 $A_i$ 变成 $A_i'$（因为取了石子，所以 $A_i' < A_i$）。

操作后的新异或和为：

$$S' = S \oplus A_i \oplus A_i' = 0 \oplus A_i \oplus A_i' = A_i \oplus A_i'$$

由于两个不同的数字异或结果绝对不可能为 0（$A_i \neq A_i'$），所以 $S'$ 必定不等于 0。

**结论：** 如果你接手了 $S=0$ 的烂摊子，无论你多么聪明，你取完石子后，交给对手的局面必定是 $S \neq 0$。

### 3. 面对 $S \neq 0$，必然存在一种操作让 $S = 0$（必胜态总有绝杀）

假设当前局面异或和 $S \neq 0$。

我们将 $S$ 写成二进制形式，找到它的**最高位的 1**（假设在第 $k$ 位）。

根据异或的性质，在 $A_1$ 到 $A_n$ 中，**必然至少存在一堆石子 $A_i$**，其二进制的第 $k$ 位也是 1。

我们只要从这堆石子中取走一部分，使其剩下的数量变为 $A_i' = A_i \oplus S$。

为什么这是一个合法的取石子动作？

因为 $A_i$ 的第 $k$ 位是 1，$S$ 的第 $k$ 位也是 1，两者异或后第 $k$ 位变成了 0，而更高的位保持不变。因此 $A_i' < A_i$，这意味着我们确实是“取走”了石子，符合游戏规则。

取完之后，新的异或和为：

$$S' = S \oplus A_i \oplus A_i' = S \oplus A_i \oplus (A_i \oplus S) = 0$$

**结论：** 面对 $S \neq 0$ 的先手，总是能通过数学计算，精准地取走一定数量的石子，把 $S=0$ 的死局塞给对手。

## 策略推演示例

假设桌面上有 3 堆石子，数量分别为 **3, 4, 5**。

**第一步：计算初始异或和**

将其转为二进制计算：

- 3 = `011`
    
- 4 = `100`
    
- 5 = `101`

$$S = 011 \oplus 100 \oplus 101 = 010$$

十进制的 $S = 2 \neq 0$。因此，**先手必胜**。

**第二步：寻找制胜操作**

$S$ 的二进制是 `010`，其最高位的 1 在倒数第 2 位。

观察三堆石子，倒数第 2 位是 1 的只有第一堆的 3（`011`）。

所以，先手必须对第一堆进行操作。目标数量是 $A_1' = A_1 \oplus S = 3 \oplus 2 = 1$。

**动作：** 先手从第一堆（3个）中取走 2 个石子，留下 1 个。

**第三步：交给对手绝境**

现在的三堆石子变成了 **1, 4, 5**。

新的异或和为：$1 \oplus 4 \oplus 5 = 001 \oplus 100 \oplus 101 = 000$。

先手成功把 $S = 0$ 的局面交给了后手。此后，无论后手从哪一堆取什么数量，异或和都会变成非 0。先手只要重复上述计算，每次都将局面重新打回 0，最终后手将面对所有石子堆全为 0 的终局。
