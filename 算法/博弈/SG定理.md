SG 定理（Sprague-Grundy Theorem）是公平组合游戏（ICG）的终极统一理论。它揭示了一个惊人的数学事实：**所有可以分解为多个独立子游戏的公平组合游戏，其本质上完全等价于尼姆博弈（Nim Game）。**

要理解这个转换过程，我们需要按照“单局游戏评估”到“多局游戏合并”的逻辑，引入 MEX 运算和 SG 函数。

## 1. 核心工具：MEX 运算

**MEX（Minimum Excluded Value）** 是一种定义在非负整数集合上的运算。它的结果是**不属于该集合的最小非负整数**。

- $\text{mex}(\{1, 2, 3\}) = 0$ （集合中没有 0）
    
- $\text{mex}(\{0, 1, 3\}) = 2$ （集合中有 0 和 1，缺少的最小非负整数是 2）
    
- $\text{mex}(\{0, 1, 2, \dots, k\}) = k + 1$
    
- $\text{mex}(\emptyset) = 0$ （空集不包含任何非负整数，最小缺漏值为 0）
    

## 2. 单个子游戏的评估：SG 函数

**SG 函数**用于评估游戏中某个特定状态 $x$ 的胜负性质。它的计算规则是一个递归过程：**当前状态的 SG 值，等于它所有能直接到达的后继状态的 SG 值集合的 MEX 值。**

$$SG(x) = \text{mex}(\{SG(y) \mid y \text{ 是 } x \text{ 的合法后继状态}\})$$

**推导规则：**

1. **必败态（终局）：** 当一个状态没有任何合法的后继状态时（无路可走，判负），由于后继集合为空集，根据定义 $SG(\text{终局}) = \text{mex}(\emptyset) = 0$。
    
2. **胜负判定：** 如果 $SG(x) = 0$，表示当前是必败态（P态）；如果 $SG(x) > 0$，表示当前是必胜态（N态）。
    

**为什么 MEX 能反映状态转移的本质？**

如果当前状态的 $SG(x) = k$，根据 MEX 的定义，这意味着它的后继状态中**必然包含** SG 值为 $0, 1, 2, \dots, k-1$ 的状态。

换句话说，处于 $SG(x) = k$ 的玩家，可以选择一种走法，将局面的 SG 值变成 $0$ 到 $k-1$ 之间的**任何一个值**。这恰好与“面对一堆数量为 $k$ 的尼姆石子，可以取走若干个使其剩下 $0$ 到 $k-1$ 个”的操作逻辑完全一致。

## 3. SG 定理：将任意游戏转化为 Nim

当一个大游戏 $G$ 由 $n$ 个互不影响的独立子游戏 $G_1, G_2, \dots, G_n$ 组成时，玩家每回合只能选择其中一个子游戏进行一步操作。

**SG 定理指出：** 总游戏 $G$ 的状态等价于一个尼姆博弈，其中每个子游戏的 SG 值等价于一堆石子的数量。总游戏的 SG 值等于所有子游戏 SG 值的按位异或和（XOR）。

$$SG(G) = SG(G_1) \oplus SG(G_2) \oplus \dots \oplus SG(G_n)$$

- **如果 $SG(G) \neq 0$**，先手必胜。先手一定能找到一个子游戏，操作后使得整体的异或和变为 0。
    
- **如果 $SG(G) = 0$**，后手必胜。无论先手动哪个子游戏，整体异或和必然变为非 0。
    

## 计算实例演示

我们发明一个自定义规则的游戏：桌面上有 3 堆石子，数量分别为 **4、5、2**。玩家每次只能选择一堆，从中取走 **1 个、3 个或 4 个**石子（不能取其他数量）。最后无法取石子的玩家判负。

**第一步：计算单个石子堆（子游戏）在不同数量 $x$ 下的 SG 值**

合法转移是：从 $x$ 转移到 $x-1, x-3, x-4$。

- $SG(0) = \text{mex}(\emptyset) = 0$
    
- $SG(1) = \text{mex}(\{SG(0)\}) = \text{mex}(\{0\}) = 1$
    
- $SG(2) = \text{mex}(\{SG(1)\}) = \text{mex}(\{1\}) = 0$
    
- $SG(3) = \text{mex}(\{SG(2), SG(0)\}) = \text{mex}(\{0, 0\}) = 1$
    
- $SG(4) = \text{mex}(\{SG(3), SG(1), SG(0)\}) = \text{mex}(\{1, 1, 0\}) = 2$
    
- $SG(5) = \text{mex}(\{SG(4), SG(2), SG(1)\}) = \text{mex}(\{2, 0, 1\}) = 3$
    

**第二步：应用 SG 定理评估总局面**

现在我们拥有数量为 4、5、2 的三堆石子，分别代入计算出的 SG 值：

- 数量 4 的石子堆，$SG(4) = 2$
    
- 数量 5 的石子堆，$SG(5) = 3$
    
- 数量 2 的石子堆，$SG(2) = 0$
    

这个复杂规则下的游戏，在数学上被完美“降维”等价于一个传统的尼姆博弈局面：三堆石子数量分别为 2、3、0。

计算总的异或和：

$$SG_{\text{total}} = 2 \oplus 3 \oplus 0 = 010_2 \oplus 011_2 \oplus 000_2 = 001_2 = 1$$

因为 $SG_{\text{total}} = 1 \neq 0$，所以判定**当前局面先手必胜**。

为了赢，先手需要将总异或和变成 0。因为 $2 \oplus 0 = 2 \neq 3$，$0 \oplus 3 = 3 \neq 2$，唯一的解是让 $SG(5)$ 的值从 3 变成 2（使得 $2 \oplus 2 \oplus 0 = 0$）。

查阅上表，$SG(4)=2$，这意味着先手应该从有 5 个石子的那堆里取走 1 个石子（剩下 4 个），绝杀成立。
