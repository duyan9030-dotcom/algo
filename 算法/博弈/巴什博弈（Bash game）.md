巴什博弈（Bash Game）是博弈论中最基础、最经典的组合游戏之一。它属于完全信息博弈，且不存在平局。
## 游戏规则

1. 只有**一堆**物品，总数量为 $n$ 个。
    
2. 有两名玩家轮流从中取走物品。
    
3. 每次至少取 $1$ 个，最多取 $m$ 个（即取走数量 $x$ 满足 $1 \le x \le m$）。
    
4. **最后把物品取光的人获胜**（即没有物品可取的人失败）。
## 核心原理与必胜策略

解决巴什博弈的关键在于寻找“安全数字”（即必败态）。在这个游戏中，这个数字是 $m + 1$。

假设物品总数恰好是 $m + 1$ 个。此时轮到先手取物品，无论他取多少个（最少 $1$ 个，最多 $m$ 个），剩下的物品数量必定在 $1$ 到 $m$ 之间。那么后手只需一次性把剩下的物品全部取光，后手必胜。

因此，**谁面临物品数量是 $m + 1$ 的倍数，谁就必败**。我们可以将总数 $n$ 写成以下形式：

$$n = k(m+1) + r$$

其中 $k$ 是商，$r$ 是余数（$0 \le r < m+1$）。

### 1. 先手必胜的情况： $n \pmod{m+1} \neq 0$

如果 $r \neq 0$（即 $n$ 不是 $m+1$ 的倍数），**先手必胜**。

**策略：**

- 先手第一步取走 $r$ 个物品，此时剩下的物品数量变为 $k(m+1)$，即 $m+1$ 的倍数。
    
- 接下来，无论后手取走 $x$ 个物品（$1 \le x \le m$），先手都取走 $m+1-x$ 个物品。
    
- 这样每一轮（后手+先手）取走的物品总数必定是 $m+1$。
    
- 先手始终能保证留给对方的物品数量是 $m+1$ 的倍数，直到最后留给对方 $0$ 个，先手获胜。

### 2. 后手必胜的情况： $n \pmod{m+1} = 0$

如果 $r = 0$（即 $n$ 恰好是 $m+1$ 的倍数），**后手必胜**。

**策略：**

- 无论先手第一步取走 $x$ 个物品（$1 \le x \le m$），剩下的数量必然不再是 $m+1$ 的倍数。
    
- 后手只需采用上面提到的“控制策略”，每次取走 $m+1-x$ 个物品。
    
- 每一轮物品减少 $m+1$ 个，最后必定由后手取完，后手获胜。
## 演练示例

假设物品总数 $n = 10$，每次最多取 $m = 3$ 个。

这里 $m + 1 = 4$。计算 $10 \pmod 4 = 2$。

因为余数不为 $0$，所以**先手必胜**。实战过程如下：

1. **先手**为了凑 $4$ 的倍数，第一步必须取走 $2$ 个。剩余 $8$ 个。
    
2. 此时轮到**后手**，假设他取了 $1$ 个。剩余 $7$ 个。
    
3. **先手**为了保证每一轮取走总数是 $4$，取走 $4 - 1 = 3$ 个。剩余 $4$ 个。
    
4. **后手**面临绝境，假设他取走 $3$ 个（最多也只能取 $3$ 个）。剩余 $1$ 个。
    
5. **先手**取走最后 $1$ 个，赢得游戏。

## 算法实现

在编程竞赛中，判断巴什博弈的胜负通常只需要一行代码。

C++

```C++
bool bashGame(int n, int m) {
    // 如果 n 不是 m+1 的倍数，先手必胜返回 true
    // 如果 n 是 m+1 的倍数，先手必败返回 false
    return n % (m + 1) != 0;
}
```

## 变种：让步博弈（Misère Play）

如果规则改为：**取走最后一个物品的人失败**（即被迫拿最后一个的人输）。

其策略会发生微小的变化，但核心依然围绕模除：

- 当 $n \le m$ 时，先手只需取走 $n-1$ 个，留 $1$ 个给后手，先手必胜。
    
- 推广到一般情况，只需保证留给后手的物品数量是 $k(m+1) + 1$ 即可。
    
- 结论：如果 $(n - 1) \pmod{m+1} = 0$，则后手必胜；否则先手必胜。
