前置知识：[[KMP]]

字符串哈希（String Hashing）是一种极其暴力的、但却极其精妙的字符串处理技巧。它的核心思想是将字符串映射为一个唯一的整数，从而将 $O(L)$ 的字符串比较时间骤降为 $O(1)$ 的整数比较。

以下是字符串哈希的详尽原理解析，从普通哈希的计算规则，一直深入到如何通过前缀和思想在 $O(1)$ 时间内求出任意子串的哈希值。

### 一、 核心思想：把字符串当成“数字”

在哈希表中，我们通常使用哈希函数将字符串映射为一个索引。但在字符串算法中，我们探讨的“字符串哈希”特指**多项式滚动哈希（Polynomial Rolling Hash）**。

它的核心理念是：**把字符串看作是一个 $P$ 进制的数字。**

就像十进制数 `123 = 1 * 10^2 + 2 * 10^1 + 3 * 10^0` 一样，我们把字符串 `"abc"` 也展开成类似的多项式。

### 二、 普通哈希：多项式滚动哈希

假设有一个字符串 $S = s_1 s_2 \dots s_n$（我们从下标 1 开始算）。

我们选定一个进制数 $P$，它的哈希值计算公式为：

$$Hash(S) = (s_1 \times P^{n-1} + s_2 \times P^{n-2} + \dots + s_n \times P^0) \pmod M$$

#### 1. 两个关键参数的选取

为了尽量避免“哈希冲突”（即两个不同的字符串算出来同一个数字），我们需要精心挑选进制 $P$ 和模数 $M$：

- **进制基数 $P$**：通常选择质数 **$131$** 或 **$13331$**。经验证明，这两个数字发生冲突的概率极小。
    
- **模数 $M$**：通常取一个极大的质数（如 $10^9+7$）。但在实际 C++ 编程中，有一个极其聪明的取巧办法：**直接使用 `unsigned long long` 类型**。
    
    - 由于 `unsigned long long` 的最大值是 $2^{64}-1$，当计算结果超出这个范围时，计算机会自动丢弃高位，这在数学上等价于**自动对 $2^{64}$ 取模**（自然溢出）。这就省去了昂贵的 `%` 运算。
#### 2. 递推计算

计算一个长字符串的哈希值，不需要每次从头套公式，可以用前缀递推的方式：

设 $H[i]$ 为前 $i$ 个字符组成的字符串的哈希值，则：

$$H[i] = (H[i-1] \times P + s_i) \pmod M$$

这就像是在十进制中，把 `12` 变成 `123` 的操作是：`12 * 10 + 3`。

### 模板C++

```C++
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 10001;
const unsigned long long base_val = 499;

// 使用 unsigned long long 替代 long 以实现自然溢出取模
unsigned long long nums[MAXN];
int n;

// 字符映射函数
int v(char c) {
    if (c >= '0' && c <= '9') {
        return c - '0' + 1;
    } else if (c >= 'A' && c <= 'Z') {
        return c - 'A' + 11;
    } else {
        return c - 'a' + 37;
    }
}

// 计算整个字符串的哈希值
unsigned long long get_value(const string& s) {
    if (s.empty()) return 0;
    
    unsigned long long ans = v(s[0]);
    for (size_t i = 1; i < s.length(); i++) {
        ans = ans * base_val + v(s[i]);
    }
    return ans;
}

// 统计不同哈希值的个数
int cnt() {
    if (n == 0) return 0;
    
    sort(nums, nums + n);
    
    int ans = 1;
    for (int i = 1; i < n; i++) {
        if (nums[i] != nums[i - 1]) {
            ans++;
        }
    }
    return ans;
}

int main() {
    // 提升 cin/cout 的读写效率，对应原代码的 BufferedReader 和 PrintWriter
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    if (cin >> n) {
        string s;
        for (int i = 0; i < n; i++) {
            cin >> s;
            nums[i] = get_value(s);
        }
        cout << cnt() << "\n";
    }
    
    return 0;
}
```
### 三、 进阶：快速求解任意子串的哈希值

这是字符串哈希最强大的地方。如果你知道了一个长字符串的前缀哈希值，你就能像查“前缀和”一样，在 **$O(1)$** 时间内算出它内部**任意一个子串**的哈希值。

#### 1. 前缀和的类比

假设原串为 $S = \text{"abcde"}$，我们要单独求子串 `"de"` 的哈希值。

已知：

- $H[5]$ 是 `"abcde"` 的哈希值。
    
- $H[3]$ 是 `"abc"` 的哈希值。
    

怎么从 `"abcde"` 中剔除 `"abc"` 的影响，只留下 `"de"` 呢？

直接相减 $H[5] - H[3]$ 是不行的，因为它们在多项式中的“权重”不对。

- 在 $H[5]$ 中，字符 'a' 的权重是 $P^4$，'b' 是 $P^3$，'c' 是 $P^2$。
    
- 在 $H[3]$ 中，字符 'a' 的权重是 $P^2$，'b' 是 $P^1$，'c' 是 $P^0$。
    

#### 2. 对齐权重（位移）

为了让 $H[3]$ 的权重和 $H[5]$ 中前半部分的权重对齐，我们需要把 $H[3]$ 向左移动 2 位（即乘以 $P^2$）。

此时，$H[3] \times P^2$ 刚好代表了 `"abc00"` 的哈希值。

用 `"abcde"` 减去 `"abc00"`，得到的就是 `"de"` 的哈希值！

即：$Hash("de") = H[5] - H[3] \times P^2$

#### 3. 核心公式

提取出通用公式：若要求原串中从下标 $l$ 到 $r$（1-based）的子串哈希值，其公式为：

$$Hash(l, r) = H[r] - H[l-1] \times P^{r - l + 1}$$

_注意：$r - l + 1$ 就是该子串的长度。为了快速计算，我们需要提前预处理好 $P$ 的各次方数组。_

### 模板C++

```C++
// 对应原代码的 MAXN 和 base
const int MAXN = 100005;
// C++ 中为了避免与标准库冲突，重命名了 base 为 base_val
const unsigned long long base_val = 499; 

// C++ 中使用 unsigned long long 来实现自然溢出取模（等同于 Java 中 long 的溢出）
// 为了避免与标准库的 pow 函数冲突，重命名为 p_pow
unsigned long long p_pow[MAXN]; 
// 避免与 std::hash 冲突，重命名为 h
unsigned long long h[MAXN];     

// 预处理字符串，生成前缀哈希数组和 base 的次方数组
void build(const string& s) {
    int n = s.length();
    if (n == 0) return;

    p_pow[0] = 1;
    for (int i = 1; i < n; i++) {
        p_pow[i] = p_pow[i - 1] * base_val;
    }

    h[0] = s[0] - 'a' + 1;
    for (int i = 1; i < n; i++) {
        h[i] = h[i - 1] * base_val + s[i] - 'a' + 1;
    }
}

// 返回 s[l...r] 的哈希值
unsigned long long get_hash(int l, int r) {
    unsigned long long ans = h[r];
    if (l > 0) {
        ans -= h[l - 1] * p_pow[r - l + 1];
    }
    return ans;
}

// 字符串哈希得到子串哈希
// 利用字符串哈希的便利性替代KMP算法
int strStr(const string& str1, const string& str2) {
    if (str2.empty()) return 0;
    if (str1.empty() || str1.length() < str2.length()) return -1;

    int n = str1.length();
    int m = str2.length();
    
    // 对主串进行预处理
    build(str1);
    
    // 单独计算模式串 str2 的哈希值 h2
    unsigned long long h2 = str2[0] - 'a' + 1;
    for (int i = 1; i < m; i++) {
        h2 = h2 * base_val + str2[i] - 'a' + 1;
    }
    
    // 滑动窗口遍历主串，寻找与模式串哈希值相同的子串
    for (int l = 0, r = m - 1; r < n; l++, r++) {
        if (get_hash(l, r) == h2) {
            return l; // 找到首次出现的位置，返回起始下标
        }
    }
    
    return -1; // 未找到匹配
}
```
