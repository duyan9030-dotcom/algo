KMP（Knuth-Morris-Pratt）算法是一种用于**字符串匹配**的高效算法。它的核心优势在于将暴力匹配的 O(m×n) 时间复杂度优化到了**严格的 O(m+n)**。

以下是该算法的详尽原理解析及 C++(STL) 实现。

### 一、 核心思想：拒绝无意义的回退

在传统的暴力匹配（Brute Force）中，如果主串和模式串在某个字符处匹配失败，主串的指针会被迫回退到上一次匹配起点的下一个位置，重新开始比较。 KMP算法的核心在于：**主串的指针永远不回退（只进不退）。** 当发生不匹配时，它利用模式串自身隐藏的“局部对称性”信息，让模式串向右滑动尽可能远的合理距离，直接跳过那些必然不可能匹配的位置。

### 二、 核心概念：最长公共前后缀与 Next 数组

为了知道发生不匹配时模式串该往右滑多远，KMP 引入了 `next` 数组（有时也叫 `lps` 数组，Longest Proper Prefix which is also Suffix）。

#### 1. 前缀与后缀

- **真前缀**：包含首字符，但不包含尾字符的所有子串。
    
- **真后缀**：包含尾字符，但不包含首字符的所有子串。
    
- 例如，字符串 `"ABABA"`：
    
    - 真前缀有：`A`, `AB`, `ABA`, `ABAB`
        
    - 真后缀有：`A`, `BA`, `ABA`, `BABA`
        
    - 它的**最长公共前后缀**是 `"ABA"`，长度为 3。
        

#### 2. `next` 数组的物理意义

`next[i]` 表示：在模式串的子串 `pattern[0...i]` 中，**最长公共前后缀的长度**。 _神奇的性质_：这个长度值刚好等于发生不匹配时，模式串**下一个应该用来继续比较的字符的索引**。

**示例：** 模式串 `pattern = "ABABC"` 的 `next` 数组计算

- `i=0`，`"A"`：无前后缀，`next[0] = 0`
    
- `i=1`，`"AB"`：前缀"A"，后缀"B"，无交集，`next[1] = 0`
    
- `i=2`，`"ABA"`：前缀"A"，后缀"A"，`next[2] = 1`
    
- `i=3`，`"ABAB"`：前缀"AB"，后缀"AB"，`next[3] = 2`
    
- `i=4`，`"ABABC"`：前缀不等于后缀，`next[4] = 0`
    

### 三、 算法核心步骤

#### 1. 遇到不匹配时怎么跳？

假设主串为 `S`，模式串为 `P`。 当 `S[i] != P[j]` 时，说明 `P[0...j-1]` 这一段是匹配成功的。 此时，我们去查 `next[j-1]`，它告诉我们已经匹配的这部分字符串中，有多长的前缀和后缀是相同的。 因为这段后缀已经和主串匹配过了，所以这部分前缀也必然能和主串匹配。我们只需将模式串指针 `j` 回退到 `next[j-1]`，然后继续与 `S[i]` 比较即可。主串指针 `i` 原地不动。

#### 2. 如何高效构建 Next 数组？（自己匹配自己）

求解 `next` 数组的过程，本质上就是模式串**自己和自己做 KMP 匹配**的过程。 我们维护两个指针：`i` 遍历模式串的当前位置（后缀末尾），`j` 表示当前最长公共前后缀的长度（同时也指向前缀的末尾的下一个字符）。

- 如果 `P[i] == P[j]`，说明前后缀可以延长，`j++`，`next[i] = j`。
    
- 如果 `P[i] != P[j]`，说明当前前后缀断了，需要找次长的公共前后缀，即让 `j` 回退到 `next[j-1]`，继续比较，直到匹配成功或 `j` 退回 0。

### 四、 完整代码实现 (C++ with STL)

C++

```C++
// 得到next数组
vector<int> nextArray(const string& s, int m) {
    // 如果模式串长度为1，直接返回包含 -1 的数组
    if (m == 1) {
        return {-1};
    }
    
    vector<int> next(m);
    next[0] = -1; // 规定0位置的值为-1
    next[1] = 0;  // 规定1位置的值为0
    
    // i表示当前要求next值的位置
    // cn表示当前要和前一个字符比对的下标，同时也代表了前一个字符的最长公共前后缀长度
    int i = 2, cn = 0;
    while (i < m) {
        if (s[i - 1] == s[cn]) {
            // 如果前一个字符和 cn 位置的字符相等，最长公共前后缀长度加1
            next[i++] = ++cn;
        } else if (cn > 0) {
            // 如果不相等，且 cn 还能往前跳，就让 cn 回退到它自己的 next 值的位置
            cn = next[cn];
        } else {
            // 如果 cn 已经退到了 0 还是不匹配，说明当前位置没有公共前后缀
            next[i++] = 0;
        }
    }
    return next;
}

// KMP算法
int kmp(const string& s1, const string& s2) {
    if (s1.empty() || s2.empty() || s1.length() < s2.length()) {
        return -1;
    }
    
    // s1中当前比对的位置是x
    // s2中当前比对的位置是y
    int n = s1.length(), m = s2.length();
    int x = 0, y = 0;
    
    // O(m)
    vector<int> next = nextArray(s2, m);
    
    // O(n)
    while (x < n && y < m) {
        if (s1[x] == s2[y]) {
            // 如果当前字符匹配，共同往后移动
            x++;
            y++;
        } else if (y == 0) {
            // 如果不匹配，且 y 已经处于模式串的开头位置 (等同于 next[y] == -1)
            // 说明主串当前的字符连模式串的第一个字符都匹配不上，只能主串单独往后移动
            x++;
        } else {
            // 如果不匹配，且 y 不是开头，y 根据 next 数组进行回退
            y = next[y];
        }
    }
    
    // 如果 y 越界了(y == m)，说明 s2 已经全部匹配完了，返回起始下标
    // 否则说明整个 s1 遍历完了都没匹配出 s2，返回 -1
    return y == m ? x - y : -1;
}
```

### 五、 复杂度分析

- **时间复杂度：O(m+n)**
    
    - 计算 `next` 数组时，外层循环执行 m 次，内层 `while` 循环中的回退操作 `j = next[j-1]` 实际上是在减小 `j` 的值。由于每次 `for` 循环 `j` 最多增加 1，所以 `j` 增加的总次数不超过 m。因此 `while` 循环里减小 `j` 的操作总共也不会超过 m 次。此部分复杂度为 O(m)。
        
    - 同理，主串匹配的过程，`i` 遍历 n 次，`j` 的回退次数总量不超过 n 次。此部分复杂度为 O(n)。
        
    - 总时间复杂度严格为 O(m+n)。
        
- **空间复杂度：O(m)** 我们需要一个与模式串长度相等的 `next` 数组来保存部分匹配信息，因此消耗了 O(m) 的额外空间。主串无论多长，都不会增加空间消耗。
