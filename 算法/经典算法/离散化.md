离散化（Discretization）是算法竞赛中用于处理大范围、稀疏数据的核心空间压缩技巧。它的本质是**保持原序列大小关系的前提下，把庞大且稀疏的值映射到紧凑的较小区间中**。

当数据的取值范围很大（例如 $10^9$），但数据的个数较少（例如 $10^5$）时，我们无法直接开辟大小为 $10^9$ 的数组来充当计数器或线段树的下标。此时，通过离散化，我们可以将这些值映射到 $1$ 到 $N$ 的连续区间内，从而将空间复杂度从 $O(\text{值域})$ 降至 $O(N)$。

### 离散化的标准 C++ 实现 (借助 STL)

在 C++ 中，最经典、最高效的离散化方法依赖于 `std::vector` 和三个 STL 算法：`std::sort`、`std::unique` 和 `std::lower_bound`。

#### 1. 核心代码模板

C++

```C++
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    // 原始数组
    vector<int> a = {1000000000, 20, 500, 20, -999};
    
    // 1. 复制一份用于去重排序的数组
    vector<int> vals = a; 
    
    // 2. 排序 (O(N log N))
    sort(vals.begin(), vals.end());
    
    // 3. 去重 (O(N))
    // unique 会将重复元素移到数组末尾，并返回指向第一个重复元素的迭代器
    // erase 将这些无用的尾部元素真正删除
    vals.erase(unique(vals.begin(), vals.end()), vals.end());
    
    // 4. 查询映射值 (O(log N))
    // 将原数组 a 中的元素替换为离散化后的排名（1-based）
    for (int i = 0; i < a.size(); i++) {
        // lower_bound 返回指向第一个大于等于 a[i] 的元素的迭代器
        // 减去 vals.begin() 得到 0-based 索引，+1 得到 1-based 索引
        int rank = lower_bound(vals.begin(), vals.end(), a[i]) - vals.begin() + 1;
        
        cout << "原值: " << a[i] << " -> 离散化后的值: " << rank << "\n";
    }

    return 0;
}
```

**输出结果：**

```
原值: 1000000000 -> 离散化后的值: 4
原值: 20 -> 离散化后的值: 2
原值: 500 -> 离散化后的值: 3
原值: 20 -> 离散化后的值: 2
原值: -999 -> 离散化后的值: 1
```

### 关键细节剖析

#### 1. `unique` 的工作原理与避坑

`std::unique` 并**不会**真正改变容器的大小。它只是通过双指针，将不重复的元素依次覆盖到数组前面，并把重复的元素留在后面。它返回的是一个迭代器，指向“去重后连续序列的末尾（即第一个垃圾数据的位置）”。

**必须配合 `erase` 使用**，否则二分查找 `lower_bound` 会在包含垃圾数据的数组上进行，导致完全错误的结果。

#### 2. 0-Indexed 还是 1-Indexed？

- **1-Based（从 1 开始记数）**：上面模板中末尾加了 `+ 1`。这在配合**树状数组 (Fenwick Tree)** 时是必须的，因为树状数组的下标绝对不能为 0（会导致死循环）。
    
- **0-Based（从 0 开始记数）**：如果不加 `+ 1`，则映射后的取值范围是 $0$ 到 $N-1$。如果配合线段树或普通数组统计，这种写法更加方便自然。
    

### 实战应用场景

离散化极少作为单独的考点，它通常是高级数据结构的前置预处理步骤。

#### 场景一：树状数组求逆序对（值域极大时）

如果给定的序列 $A$ 包含极大的数字，无法直接用树状数组的下标表示数值，就需要先离散化。

**流程：**

1. 读入序列 $A$。
    
2. 对 $A$ 进行上述的离散化操作，得到序列 $A'$。
    
3. 倒序（或正序）遍历 $A'$，将 $A'[i]$ 插入树状数组，并在树状数组中查询比 $A'[i]$ 小（或大）的元素个数。

#### 场景二：扫描线算法 (Sweep Line) 求矩形面积并

在二维平面上有 $N$ 个矩形，求它们覆盖的总面积。矩形的坐标极大，但最多只有 $2N$ 条横边和纵边。

**流程：**

1. 提取所有矩形的横坐标（或纵坐标），存入数组。
    
2. 对这些坐标进行排序、去重完成离散化。
    
3. 原本跨度数亿的物理坐标域，被压缩成了 $1$ 到 $2N$ 的线段树下标区间。线段树的每个叶子节点 $[i, i+1]$ 对应一段真实的物理长度（即 `vals[i] - vals[i-1]`）。

### 替代方案：基于 `std::map` 的离散化

在某些对常数要求不高、或者需要动态插入数据的场景下，可以使用 `std::map` 或 `std::unordered_map` 进行离散化：

C++

```C++
#include <map>
#include <vector>

// ... 
vector<int> a = {100, 20, 500, 20};
map<int, int> rank_map;

// 1. 利用 map 自动排序去重的特性收集节点
for (int x : a) rank_map[x] = 0;

// 2. 赋予排名
int rank = 1;
for (auto& pair : rank_map) {
    pair.second = rank++;
}

// 3. 原地替换
for (int& x : a) {
    x = rank_map[x];
}
```

**对比评估：**

`map` 版本的代码更短，但由于红黑树的节点分配和复杂的常数开销，其速度通常比 `vector + sort + lower_bound` 慢 3 到 5 倍。在严格的算法竞赛（如 Codeforces 或 ICPC）中，当 $N \ge 10^5$ 时，强烈建议使用标准 `vector` 离散化模板以防止 TLE。
