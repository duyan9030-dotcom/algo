**1. 原理**

二维前缀和 `S[i][j]` 表示原二维数组 `A` 中，以 $(1, 1)$ 为左上角，以 $(i, j)$ 为右下角的矩形区域内所有元素的和。运用了容斥原理。

- **构建公式**：整个区域 = 上方区域 + 左侧区域 - 左上角重复相加的区域 + 当前格子。
    
    `S[i][j] = S[i-1][j] + S[i][j-1] - S[i-1][j-1] + A[i][j]`
    
- **查询子矩阵和**：要求以 $(x_1, y_1)$ 为左上角，$(x_2, y_2)$ 为右下角的矩阵和。
    
    `Sum = S[x2][y2] - S[x1-1][y2] - S[x2][y1-1] + S[x1-1][y1-1]`

**2. C语言实现**

```C++
#include <stdio.h>

#define MAX_N 105

int main() {
    int n = 3, m = 3;
    // 原二维矩阵 (下标 1 开始)
    int A[MAX_N][MAX_N] = {
        {0, 0, 0, 0},
        {0, 1, 2, 3},
        {0, 4, 5, 6},
        {0, 7, 8, 9}
    };
    int S[MAX_N][MAX_N] = {0};

    // 1. 构建二维前缀和 O(N*M)
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            S[i][j] = S[i-1][j] + S[i][j-1] - S[i-1][j-1] + A[i][j];
        }
    }

    // 2. 查询子矩阵和: 左上角(2, 2)，右下角(3, 3) O(1)
    int x1 = 2, y1 = 2, x2 = 3, y2 = 3;
    int sum = S[x2][y2] - S[x1-1][y2] - S[x2][y1-1] + S[x1-1][y1-1];
    
    printf("二维前缀和: 子矩阵和为 %d\n", sum); // 5 + 6 + 8 + 9 = 28
    return 0;
}
```
