**1. 原理**

与一维差分类似，构建一个二维差分矩阵 `D`，使得 `D` 的二维前缀和恰好为原矩阵 `A`。

- **区间修改**：当我们想要给原矩阵以 $(x_1, y_1)$ 为左上角，$(x_2, y_2)$ 为右下角的子矩阵整体加上常数 $c$ 时，只需要对差分矩阵 `D` 上的四个点进行 $O(1)$ 操作：
    
    1. `D[x1][y1] += c`
        
    2. `D[x2+1][y1] -= c`
        
    3. `D[x1][y2+1] -= c`
        
    4. `D[x2+1][y2+1] += c`
        
- **还原矩阵**：操作结束后，对差分矩阵 `D` 求一遍二维前缀和，就能得到最终修改后的矩阵 `A`。

**2. C语言实现**

C

```C++
#include <stdio.h>

#define MAX_N 105

// 二维差分的插入/修改操作
void insert2D(int D[][MAX_N], int x1, int y1, int x2, int y2, int c) {
    D[x1][y1] += c;
    D[x2+1][y1] -= c;
    D[x1][y2+1] -= c;
    D[x2+1][y2+1] += c;
}

int main() {
    int n = 3, m = 3;
    int A[MAX_N][MAX_N] = {
        {0, 0, 0, 0},
        {0, 1, 2, 3},
        {0, 4, 5, 6},
        {0, 7, 8, 9}
    };
    int D[MAX_N][MAX_N] = {0};

    // 1. 构建二维差分矩阵 (等同于在 1x1 的面积上加 A[i][j])
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            insert2D(D, i, j, i, j, A[i][j]);
        }
    }

    // 2. 将左上角(2,2)到右下角(3,3)的子矩阵所有元素加上 10 O(1)
    insert2D(D, 2, 2, 3, 3, 10);

    // 3. 还原二维矩阵 O(N*M)
    printf("修改后的二维矩阵:\n");
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            // 对差分矩阵求二维前缀和，得到原矩阵的值
            D[i][j] += D[i-1][j] + D[i][j-1] - D[i-1][j-1]; 
            printf("%d ", D[i][j]);
        }
        printf("\n");
    }
    // 输出第一行不变，右下角四个数字加 10 (例如 5 变成 15)
    return 0;
}
```
