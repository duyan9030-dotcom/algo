
**1. 原理**

一维前缀和数组 `S` 的第 $i$ 个元素记录了原数组 `A` 中前 $i$ 个元素的总和。

- **构建公式**：`S[i] = S[i-1] + A[i]`
    
- **查询区间 $[l, r]$ 的和**：区间 $[l, r]$ 的和等于前 $r$ 个数的和减去前 $l-1$ 个数的和。
    
- **查询公式**：`Sum = S[r] - S[l-1]`

**2. C语言实现**

```C++
#include <stdio.h>

#define MAX_N 1005

int main() {
    int n = 5;
    int A[MAX_N] = {0, 1, 2, 3, 4, 5}; // 原数组，下标 1 开始
    int S[MAX_N] = {0}; // 前缀和数组
    
    // 1. 构建前缀和数组 O(N)
    for (int i = 1; i <= n; i++) {
        S[i] = S[i-1] + A[i];
    }
    
    // 2. 查询区间 [2, 4] 的和 O(1)
    int l = 2, r = 4;
    int sum = S[r] - S[l-1];
    printf("一维前缀和: 区间[%d, %d]的和为 %d\n", l, r, sum); // 输出 9 (2+3+4)
    
    return 0;
}
```
