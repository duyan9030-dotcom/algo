**1. 原理**

差分数组 `D` 记录的是原数组 `A` 中相邻元素的差值。原数组 `A` 实际上就是差分数组 `D` 的前缀和。

- **构建公式**：`D[i] = A[i] - A[i-1]`
    
- **区间修改**：如果我们要给数组 `A` 的区间 $[l, r]$ 加上一个常数 $c$，不需要通过循环把 `A[l]` 到 `A[r]` 全加上 $c$（那样是 $O(N)$ 的复杂度）。只需利用差分数组的特性进行两步操作即可实现 $O(1)$ 修改：
    
    1. `D[l] += c` （这会导致前缀和数组从 $l$ 开始所有的元素都增加了 $c$）
        
    2. `D[r+1] -= c` （这会抵消掉 $r+1$ 及其之后元素增加的 $c$）
        
- **还原数组**：所有区间修改完成后，对 `D` 数组求一次前缀和，就能得到修改后的最终数组 `A`。
    

**2. C语言实现**

```C++
#include <stdio.h>

#define MAX_N 1005

// 差分数组的插入/修改操作
void insert(int D[], int l, int r, int c) {
    D[l] += c;
    D[r+1] -= c;
}

int main() {
    int n = 5;
    int A[MAX_N] = {0, 1, 2, 3, 4, 5};
    int D[MAX_N] = {0};
    
    // 1. 根据原数组构建差分数组 (可以看作是在 [i, i] 区间加上 A[i])
    for (int i = 1; i <= n; i++) {
        insert(D, i, i, A[i]);
    }
    
    // 2. 将区间 [2, 4] 的所有元素加上 10 O(1)
    insert(D, 2, 4, 10);
    
    // 3. 还原数组 O(N)
    for (int i = 1; i <= n; i++) {
        A[i] = A[i-1] + D[i]; // 对差分数组求前缀和就是原数组
        printf("%d ", A[i]);
    }
    // 输出: 1 12 13 14 5
    
    return 0;
}
```
