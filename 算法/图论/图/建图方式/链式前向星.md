## 一、 什么是链式前向星？

链式前向星是一种用于图建图的高级数据结构，本质上是**邻接表的静态数组实现**。

它巧妙地利用“头插法”**在数组内部模拟链表，避开了动态数组（如 C++ 中的 `std::vector`）频繁分配内存的开销，同时解决了普通指针链表空间不连续导致 CPU 缓存命中率低的问题。它是存储**稀疏图的极佳选择。

## 二、 为什么要使用链式前向星？

在图的存储方式中：

- **邻接矩阵**：空间复杂度 $O(V^2)$，极其浪费空间，仅适合稠密图。
    
- **动态数组邻接表（`vector`）**：扩容时会产生额外的内存拷贝开销，常数较大。
    
- **链式前向星**：
    
    - **极致的性能**：由于使用静态数组，内存连续，速度极快，没有动态分配内存的开销。
        
    - **空间精准**：严格分配 $O(V + E)$ 的空间，不浪费内存。
        
    - **方便找反向边**：在网络流等算法中，正反向边成对加入，可以通过异或操作瞬间找到反向边（注：若需使用 `i ^ 1` 找反向边，`cnt` 需从 `2` 开始初始化，详见下方加边操作）。
        

## 三、 核心数据结构

实现链式前向星，采用多个一维数组分别存储边的各个属性，以及一个头数组和一个边计数器。

C++

```C++
const int MAX_V = 1e5 + 5; // 最大顶点数
const int MAX_E = 2e5 + 5; // 最大边数（无向图记得开两倍）

int head[MAX_V]; // head[i] 存储以顶点 i 为起点的“最后加入”的一条边的索引
int nxt[MAX_E];  // 模拟链表的 next 指针，存储同起点的上一条边的索引
int to[MAX_E];   // 存储这条边的终点
int wei[MAX_E];  // 存储这条边的权重（无权图可省略此数组）

// 边计数器
int cnt = 1;     // 记录当前分配到了第几条边。从 1 开始计，0 被留作“空指针”标志
```

## 四、 核心操作

### 1. 初始化

在建图前，必须将 `head` 数组初始化为 `0`（因为 `cnt` 从 `1` 开始，`0` 就代表没有任何边，相当于空指针）。

C++

```C++
void init() {
    memset(head, 0, sizeof(head));
    cnt = 1; 
}
```

### 2. 加边操作 (Add Edge)

加边的过程使用的是**头插法**。每次加入一条以 $u$ 为起点的新边时，我们把它放在该顶点对应的“链表”的最前面。

C++

```C++
// 添加一条从 u 到 v，权重为 w 的边
void add_edge(int u, int v, int w) {
    nxt[cnt] = head[u]; // 1. 当前边的 nxt 指向 u 顶点之前的“第一条边”
    wei[cnt] = w;       // 2. 记录权重
    to[cnt] = v;        // 3. 记录终点
    head[u] = cnt++;    // 4. 更新 u 顶点的“第一条边”为当前边，并将计数器加一
}
```

_(注：如果是无向图，连续调用两次即可：`add_edge(u, v, w); add_edge(v, u, w);`)_

### 3. 图的遍历

当我们需要遍历从顶点 $u$ 出发的所有边时，顺着 `nxt` 指针一路找下去，直到遇到初始化的 `0`。

## 五、 局限性与注意事项

1. **不能动态扩容**：必须在写代码前预估好图的最大边数（`MAX_E`）。如果边数超过预设值，会导致数组越界崩溃。
    
2. **不方便删除边**：由于是连续数组模拟的链表，很难在物理层面删除一条边。通常的做法是增加一个 `bool is_deleted[MAX_E]` 的数组作为标记，在遍历时遇到标记为 `true` 的边直接跳过（软删除）。
